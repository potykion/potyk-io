# AGENTS.md

## Окружение

Агент работает на **Windows**, shell — **PowerShell**. Скрипты, one-liners и запись файлов — с учётом этого (без bash-heredoc; без UTF-8 BOM от `Set-Content -Encoding UTF8` — он ломает CSS/скрипты). Подробности — правило `windows-powershell.mdc`.

## Спеки и код

Функциональные спеки лежат в `templates/docs/` (на сайте — `/docs`).

Если просят поправить поведение, которое уже описано в спеке — в том же изменении обнови и спеку, чтобы она совпадала с новым поведением. Не оставляй спеку устаревшей.

Как писать и править спеку — skill «оформление спеки»: только поведение (сценарии, зачем, ожидаемый результат), без деталей реализации.

### Без аппрува

Аппрув спеки **не нужен**. Если спека уже есть в `templates/docs/` — просто дополни/обнови её под новое поведение вместе с кодом. Не останавливайся и не проси «прочитать и одобрить». Подробности — правило `spec-approval.mdc`.

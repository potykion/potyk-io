# Оглавление на markdown-странице

На страницах, собранных из markdown, можно показать оглавление по заголовкам страницы.

## Зачем

Чтобы длинные заметки (гайды, воспоминания) было удобно листать по разделам, не собирая список ссылок вручную.

## Сценарии

### Показать оглавление

В frontmatter страницы стоит `toc: true` (или другое явное «да»). На странице после заголовка (и даты, если она есть) появляется оглавление: ссылки на заголовки **h2–h4** в порядке появления, с вложенностью по уровню. Клик по пункту переносит к соответствующему заголовку.

### Без оглавления

`toc` нет, выключен или нет заголовков h2–h4 — оглавление не показывается.

# potyk-tech (`/tech/`)

Публичный раздел про технику, кодинг и резюме. В меню сайта (секция «Проекты») — пункт **Тех**. Внутри раздела сайдбар переключается на меню раздела.

## Зачем

Собрать «программистские» страницы в одном месте вместо разрозненных ссылок в общем меню.

## Сценарии

### Открыть раздел

Пользователь открывает `/tech/` (или пункт «Тех» в меню сайта).

**Ожидаемый результат:** страница раздела с заголовком `potyk-tech`. В бренде сверху и в сайдбаре — меню раздела, не общее меню potyk-io.

### Меню раздела

В **меню слева**:

- **Мои девайсы** — `/tech/devices`
- **Айос после андроида** — `/tech/ios-after-android`
- **Резюме** — `/tech/cv`
- **Софт/Сервисы** — внешняя таблица
- **Мой кодинг** — `/tech/my-code`
- **Стейт оф ИИ** — `/tech/ai`
- **ИИ-кодинг** — `/tech/ai-coding`
- **potyk-io** — возврат на главную сайта

### Страницы раздела

- `/tech/devices` — архив девайсов: книги, телефоны, часы, наушники, мыши и т.п. (раньше `/collections/devices`)
- `/tech/ios-after-android` — впечатления от айфона после андроида (плюсы/минусы)
- `/tech/cv` — резюме (раньше `/n/cv`)
- `/tech/my-code` — кодинг-проекты и заметки (раньше `/code`)
- `/tech/ai` — заметка про ИИ (раньше `/code/ai`)
- `/tech/ai-coding` — заметка про ИИ-кодинг (раньше `/code/ai-coding`)

Старые URL ведут на новые страницы.

# Находки

Раздел «Находки» на `/findings`: очередь «посмотреть позже», просмотренное по неделям и старый архив внизу страницы.

## Зачем

Быстро откладывать ссылки (часто ютуб) в свой список, а не в чужой интернет, и потом отмечать, что уже посмотрел.

## Что на странице

- легенда типов (🎵 музончик, 📹 ютуб, 🎮 игрушки, 🎥 кинцо, 🖼️ картинка);
- **Посмотреть позже** — ещё не просмотренные, новые сверху;
- форма добавления — только для залогиненного;
- **Просмотрено** — группы по календарным неделям;
- **архив** внизу — старые находки из markdown (не из очереди).

Страница `/findings` только для залогиненного (как остальной контент potyk-io): без логина — на вход. Добавление, «просмотрено» и удаление — тоже только после логина.

В списке у каждой находки — ссылка с текстом (название или сама ссылка). Превью и картинки ролика нет.

## Сценарии

### Добавить находку

**Что делает пользователь:** выбирает тип, вставляет ссылку, нажимает «Добавить».

**Ожидаемый результат:**

1. Ссылка появляется в «Посмотреть позже».
2. Текст ссылки: эмодзи типа и название — либо сама ссылка, если названия нет.
3. Для ссылок на YouTube название берётся по сценарию [разбора YouTube-ссылки](../features/youtube-parse.md).
4. Та же ссылка уже есть — новая запись не создаётся, показывается сообщение об этом.
5. Невалидная ссылка — ошибка, запись не создаётся.

### Отметить просмотренным

**Что делает пользователь:** у пункта в очереди нажимает «просмотрено».

**Ожидаемый результат:** пункт уходит из «Посмотреть позже» в блок «Просмотрено» в текущую неделю.

### Удалить

**Что делает пользователь:** нажимает удаление у пункта в очереди или в просмотренном.

**Ожидаемый результат:** пункт исчезает со страницы.

# potyk-culture (`/culture/`)

Публичный раздел про культуру и **крыло** для соседних проектов: potyk-mu, potyk-cinema, potyk-reads, potyk-art, potyk-prikols. URL и бренды этих разделов не меняются — в глобальном меню снаружи виден пункт **Культур** (раздел potyk-culture).

В общем меню сайта (секция «Проекты») — один пункт **Культур**. На хабе `/culture/` и во всех разделах крыла (mu, cinema, reads, art, prikols) сайдбар — **одно и то же** меню с секциями по проектам.

## Сценарии

### Открыть раздел

Пользователь открывает `/culture/` (или пункт «Культур» в меню сайта).

**Ожидаемый результат:** страница раздела с заголовком `potyk-culture`. В бренде сверху и в сайдбаре — меню раздела, не общее меню potyk-io. На главной — сетка карточек страниц раздела (Театр, Интернет, ТВ / Нулевые и т.д.). В глобальном меню нет отдельных пунктов potyk-mu / cinema / reads / art / prikols.

### Меню крыла

В **меню слева** на `/culture/` и у соседей (mu, cinema, reads, art, prikols) одинаковые секции по проектам; внутри каждой — разделы этого проекта:

- **potyk-culture** — Театр, Интернет, ТВ / Нулевые.
- **Музыка** — статьи (главная `/mu/`), исполнители, лор и остальные пункты меню potyk-mu.
- **Кино** — подборки, где смотреть кино, вьетнамское кино.
- **Чтение** — главная potyk-reads.
- **Арт** — главная potyk-art и Инста.
- **Приколы** — главная potyk-prikols.
- **potyk-io** — возврат на главную сайта.

Бренд сверху остаётся локальным разделу (`potyk-culture` / `potyk-mu` / …).

### Markdown-страницы раздела

**Зачем:** складывать тематические подборки (ссылки, заметки) рядом с главной раздела.

**Что делает пользователь:** открывает пункт меню, карточку на главной или URL вида `/culture/<страница>`.

**Ожидаемый результат:** страница с markdown-контентом из `templates/potyk-culture/`. Несуществующий путь — 404.

### Список посещений (Театр)

**Зачем:** видеть, что уже смотрел: название, тип, где и когда, с полезными ссылками.

**Что делает пользователь:** открывает `/culture/teatr` (или «Театр» в меню / карточку на главной).

**Ожидаемый результат:**

1. Виден список посещений (спектакли и мюзиклы).
2. У каждой записи: название, тип (спектакль / мюзикл), автор пьесы (если есть), локация/театр, длительность, был ли антракт, дата посещения, комментарий (если есть).
3. Если у названия есть ссылка на постановку — название кликабельно и ведёт на неё (в новой вкладке).
4. Если у локации есть ссылка на карту/театр — локация кликабельна и ведёт туда (в новой вкладке).
5. Список отсортирован по дате посещения: сначала свежие.
6. Если посещений нет — на странице видно, что список пуст.

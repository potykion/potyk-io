# Рестораны (`/food/rest`)

Список мест, куда ходить есть: смотришь ленту, фильтруешь по тегам, при желании добавляешь новые из админки.

## Сценарии

### Смотреть список

Открываешь `/food/rest`: список всех ресторанов (название, метро, теги, ссылка на Яндекс.Карты).

Над списком — чипы по всем тегам из базы.

### Фильтр по тегам

Жмёшь чип (например «Пиво») — в списке остаются только рестораны с этим тегом.

Можно включить несколько чипов: остаются места, у которых есть **хотя бы один** из выбранных тегов. Повторный клик по чипу снимает фильтр.

### Админка

Со страницы списка кнопка «Админка» ведёт на `/food/rest/admin` (нужен логин).

Там форма добавления: название, ссылка на Яндекс.Карты, метро, теги. Метро и теги выбираешь из уже использованных или вводишь новые. После сохранения ресторан появляется в списке.

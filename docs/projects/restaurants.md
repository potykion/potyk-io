# Рестораны (`/food/restaurants`)

Отзывы о местах, куда ходить есть: сетка карточек с обложками, фильтр по тегам, клик открывает заметку про ресторан.

## Сценарии

### Смотреть список

Открываешь `/food/restaurants`: сетка [контент-карточек](../components/content-card.md) в режиме **4 колонки** (на мобилке сразу **2**) — обложка, название.

Над сеткой — чипы по всем тегам из отзывов.

Клик по карточке открывает страницу отзыва.

### Фильтр по тегам

Жмёшь чип — в сетке остаются только рестораны с этим тегом.

Можно включить несколько чипов: остаются места, у которых есть **хотя бы один** из выбранных тегов (ИЛИ). Повторный клик по чипу снимает фильтр.

Если ни один ресторан не подходит — видно, что список пуст.

### Заметка о ресторане

На странице отзыва — свойства (теги, ссылка на Я.Карты, цены, дата посещения — что заполнено), фото в ряд и текст.

### Меню potyk-food

В сайдбаре potyk-food пункт «Рестораны» ведёт на `/food/restaurants`. Старые ссылки на список с фильтрами и гайды (`/food/rest`, `/food/rest/guide`, `/food/rest/msk-basics`, фуд-гайд 2026) в меню не показываются.

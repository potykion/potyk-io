# Рестораны (`/food/restaurants`)

## Что/Зачем

- https://potyk.io/food/restaurants
- Зачем: иметь базу рестиков куда сходить и что съест

## Дизайн

### Главная - `/food/restaurants`

- Фильтры из тегов - фильтрует ресты по ИЛИ вхождению тега
- 4-кол грид с контент-карточками
- Карточка открывает страницу ресторана, состоит из cover и названия
- В сайдбаре активен пункт «Рестораны» только на точном URL `/food/restaurants` (не на `/food/rest` и не на вложенных страницах)

### Страница ресторана - `/food/restaurants/<slug>`

- Название
- Свойства
- Фотки в flex блоке
- Отзыв

#### Свойства

- Теги (`tags`): кухня заведения, типовые блюда заведения
- Я.Карты (`maps`): ссылка на Яндекс карты
- Цены (`prices`): высокие/средние/низкие
- Дата посещения (`visited`): например 2026-09-02

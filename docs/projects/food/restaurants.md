# Рестораны

## Что/Зачем

База мест, куда сходить и что съесть: быстрый список и отзывы.

## Список — `/food/rest`

В меню potyk-food пункт «Рестораны» ведёт сюда.

**Что делает пользователь:** открывает `/food/rest` (или пункт меню).

**Ожидаемый результат:** список ресторанов с фильтрами по тегам (ИЛИ). В сайдбаре активен пункт «Рестораны», а не «Рецепты».

## Отзывы — `/food/restaurants`

Сетка отзывов с обложками; страница ресторана — `/food/restaurants/<slug>` (название, свойства, фото, отзыв). На этих URL тоже активен пункт «Рестораны».

### Свойства на странице отзыва

- Теги (`tags`): кухня заведения, типовые блюда
- Я.Карты (`maps`): ссылка на Яндекс карты
- Цены (`prices`): высокие/средние/низкие
- Дата посещения (`visited`): например 2026-09-02

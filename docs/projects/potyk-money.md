# potyk-money (`/money/`)

Крыло для денежных разделов: potyk-fin (учёт) и potyk-invest. URL и бренды этих разделов не меняются — в глобальном меню снаружи виден только **potyk-money**.

В общем меню сайта (секция «Проекты») — один пункт **potyk-money**. Внутри `/money/` сайдбар — меню раздела с секциями «Учет» и «Инвест».

## Сценарии

### Открыть раздел

Пользователь открывает `/money/` (или пункт «potyk-money» в меню сайта).

**Ожидаемый результат:** страница раздела с заголовком `potyk-money`. В бренде сверху и в сайдбаре — меню раздела, не общее меню potyk-io. На главной — карточки секций (Учет → potyk-fin, Инвест → potyk-invest). В глобальном меню нет отдельных пунктов potyk-fin / potyk-invest.

### Меню раздела

В **меню слева** — секции:

- **Учет** — учёт расходов и сбережений (potyk-fin).
- **Инвест** — новости, сделки, фонды, зависимости (разделы potyk-invest).
- **potyk-io** — возврат на главную сайта.

### Из секции-соседа назад в крыло

Пользователь в potyk-fin / potyk-invest нажимает в навигации раздела **potyk-money** (или «назад» в учёте).

**Ожидаемый результат:** открывается `/money/` (хаб крыла), а не главная potyk-io.

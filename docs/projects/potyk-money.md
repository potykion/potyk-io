# potyk-money (`/money/`)

Крыло для денежных разделов: potyk-fin (учёт) и potyk-invest. URL и бренды этих разделов не меняются — в глобальном меню снаружи виден пункт **Бабло** (раздел potyk-money).

В общем меню сайта (секция «Проекты») — один пункт **Бабло**. На хабе `/money/` и во всех разделах крыла (`/fin/`, `/invest/…`) сайдбар — **одно и то же** меню с секциями «Учет» и «Инвест».

## Сценарии

### Открыть раздел

Пользователь открывает `/money/` (или пункт «Бабло» в меню сайта).

**Ожидаемый результат:** страница раздела с заголовком `potyk-money`. В бренде сверху и в сайдбаре — меню крыла, не общее меню potyk-io. На главной — карточки секций (Учет → potyk-fin, Инвест → potyk-invest). В глобальном меню нет отдельных пунктов potyk-fin / potyk-invest.

### Меню крыла

В **меню слева** на `/money/`, `/fin/` и `/invest/…` одинаковые секции:

- **Учет** — учёт расходов и сбережений (potyk-fin).
- **Инвест** — новости, сделки, фонды, зависимости, пассивный доход (разделы potyk-invest).
- **potyk-io** — возврат на главную сайта.

Бренд сверху остаётся локальным разделу (`potyk-money` / `potyk-fin` / `potyk-invest`).

### Пассивный доход

Пользователь открывает пункт «Пассивный доход» в секции «Инвест» (или URL `/invest/passive-income`).

**Ожидаемый результат:** гайд про инструменты пассивного дохода в контексте potyk-invest (меню крыла «Бабло», бренд potyk-invest). Старый адрес `/guides/passive-income` ведёт на новый.

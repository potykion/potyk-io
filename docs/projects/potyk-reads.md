# potyk-reads (`/reads/`)

Публичный раздел про чтение. В глобальном меню сайта отдельного пункта нет — раздел доступен из **меню potyk-culture** (секция «Чтение»). URL и бренд прежние. Внутри раздела сайдбар переключается на меню раздела (как у potyk-art).

## Сценарии

### Открыть раздел

Пользователь открывает `/reads/` (или пункт «Главная» / «Чтение» в меню potyk-culture).

**Ожидаемый результат:** страница раздела с заголовком `potyk-reads`. В бренде сверху и в сайдбаре — меню раздела, не общее меню potyk-io.

### Меню раздела

В **меню слева**:

- **Главная** — страница раздела (`/reads/`).
- **potyk-culture** — возврат в хаб крыла (`/culture/`).

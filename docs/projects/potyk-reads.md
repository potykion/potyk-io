# potyk-reads (`/reads/`)

Публичный раздел про чтение. В меню сайта (секция «Проекты») — пункт **potyk-reads**. Внутри раздела сайдбар переключается на меню раздела (как у potyk-art).

## Сценарии

### Открыть раздел

Пользователь открывает `/reads/` (или пункт «potyk-reads» в меню сайта).

**Ожидаемый результат:** страница раздела с заголовком `potyk-reads`. В бренде сверху и в сайдбаре — меню раздела, не общее меню potyk-io.

### Меню раздела

В **меню слева**:

- **potyk-io** — возврат на главную сайта.

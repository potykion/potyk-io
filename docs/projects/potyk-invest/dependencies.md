# potyk-invest — зависимости акций (`/invest/dependencies`)

Матрица чувствительности акций к рыночным факторам (КС, Мир, золото и т.п.).

## Зачем

Быстро видеть, какие бумаги реагируют на один и тот же фактор (снижение КС, мир-коин и др.), без перелистывания карточек тикеров.

## Матрица

**Что делает пользователь:** открывает «Зависимости» в меню invest.

**Ожидаемый результат:**

1. Одна таблица на всю ширину страницы: **строки — все акции**, колонки — тикер, сектор, затем факторы (колонки одной ширины); в ячейках факторов — галочка или пусто.
2. Без разбивки по секторам отдельными блоками; тикер ведёт на страницу бумаги.
3. Заголовки колонок остаются видимыми при прокрутке таблицы.
4. По клику на «Тикер» или «Сектор» строки сортируются по этой колонке (повторный клик — обратный порядок).
5. По клику на колонку фактора заголовок выделяется жирным, в таблице остаются только акции с этой зависимостью; повторный клик по тому же фактору сбрасывает фильтр.
6. Показана только актуальная разметка из справочника тикеров (не «на лету» из текста новостей).
7. У **КС** на странице понятно направление: рост бумаги от снижения ставки, падение от повышения/паузы.
8. Если акций нет — понятное пустое состояние.

# Сетка карточек (card-grid)

Общая адаптивная сетка карточек-ссылок на главных и индексных страницах разделов.

## Зачем

Одинаково показывать списки страниц и записей ленты на разных ширинах экрана: на телефоне — одна колонка, на узком окне — две, на широком — три. Сетка подстраивается под **ширину области контента**, а не только под ширину окна браузера (важно при боковом меню и узкой колонке).

## Где используется

- главная potyk.io (`/`) — лента заметок;
- главная potyk-mu (`/mu/`) — лента блога;
- индекс исполнителей (`/mu/artists/`);
- страница исполнителя (`/mu/artists/<slug>`) — блок «Альбомы»;
- potyk-travel (`/travel/`, `/travel/memories/`, `/travel/plans/`) — списки поездок и планов;
- potyk-art (`/art/`) — проекты с обложками `.jpg`;
- potyk-food (`/food/tasting/sweets`) — сладости по категориям.

Подробнее про содержимое карточек ленты (обложки, превью, догрузка) — в [feed.md](feed.md).

## Виды карточек

В сетке два вида карточек.

### Текстовая карточка

Карточка **без обложки**: только текст по центру. Пропорции **4:3**.

Так выглядят пункты travel, текстовые записи ленты на `/` и другие записи без обложки.

### Контент-карточка

Карточка **с обложкой**: сверху изображение, снизу текст. Пропорции **3:4**.

Под обложкой:

1. **заголовок** (обязательно);
2. **подзаголовок** (опционально) — второй строкой, серым.

Если подзаголовка нет — остаётся одна строка заголовка.

**Примеры:**

- `/food/tasting/sweets` — заголовок: название сладости; подзаголовок: производитель (если есть);
- `/mu/artists/<slug>` (блок «Альбомы») — одна строка с названием альбома, без подзаголовка.

## Сценарии

### Широкая область контента

**Когда:** ширина основной колонки страницы не меньше ~768px.

**Ожидаемый результат:** три колонки карточек, сетка по центру.

### Средняя ширина

**Когда:** ширина основной колонки от ~495px до ~767px.

**Ожидаемый результат:** две колонки на всю ширину колонки.

### Узкая ширина (телефон)

**Когда:** ширина основной колонки меньше ~495px.

**Ожидаемый результат:** одна колонка; карточки на всю ширину, текст читается без сжатия в две колонки.

### Карточка в сетке

Каждый элемент — ссылка. При наведении — лёгкая тень и сдвиг вверх. Вид и пропорции — по типу карточки выше.

### Пустой список (travel)

Если в разделе travel ещё нет страниц, вместо карточек — сообщение «Пока пусто» на всю ширину сетки.

### Догрузка ленты

На страницах с лентой (не travel-списки) при прокрутке к концу подгружается следующая порция карточек; строка догрузки занимает всю ширину сетки. Поведение догрузки — в [feed.md](feed.md).

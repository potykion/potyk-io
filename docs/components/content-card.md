# Контент-карточка

Карточка-ссылка **с обложкой**: сверху изображение, снизу текст. Живёт в общей [сетке карточек](card-grid.md).

## Зачем

Показывать записи и товары с картинкой: обложка читается сразу, подпись не мешает пропорциям карточки.

## Внешний вид

По умолчанию пропорции **3:4** (портрет). Можно задать **4:3** — лента `/mu/`, youtube-превью в Videos.

Текст под обложкой по центру. При наведении — лёгкая тень и сдвиг вверх (как у любой карточки в сетке).

Под обложкой:

1. **заголовок** (обязательно);
2. **подзаголовок** (опционально) — второй строкой, серым.

Если подзаголовка нет — остаётся одна строка заголовка. Остальной текст превью в карточке не показывается.

## Где используется

- `/food/tasting/sweets` — название сладости и производитель; **3:4**;
- `/mu/artists/<slug>` (блок «Albums») — название альбома и год; **3:4**;
- `/mu/artists/<slug>` (блок «Videos») — название ролика и дата; **4:3**;
- лента `/mu/` — записи **с** `cover` в frontmatter; **4:3**;
- `/cinema/` — фильмы в подборках: русское название с годом, английское серым; **3:4**;
- potyk-art и другие сетки с обложкой — по умолчанию **3:4**.

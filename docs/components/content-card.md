# Контент-карточка

Карточка-ссылка **с обложкой**: сверху изображение, снизу текст. Живёт в общей [сетке карточек](card-grid.md).

## Зачем

Показывать записи и товары с картинкой: обложка читается сразу, подпись не мешает пропорциям портретной карточки.

## Внешний вид

Пропорции **3:4**. Текст под обложкой по центру. При наведении — лёгкая тень и сдвиг вверх (как у любой карточки в сетке).

Под обложкой:

1. **заголовок** (обязательно);
2. **подзаголовок** (опционально) — второй строкой, серым.

Если подзаголовка нет — остаётся одна строка заголовка. Остальной текст превью в карточке не показывается.

## Где используется

- `/food/tasting/sweets` — заголовок: название сладости; подзаголовок: производитель (если есть);
- `/mu/artists/<slug>` (блок «Альбомы») — одна строка с названием альбома, без подзаголовка;
- записи ленты и разделы с обложкой (например potyk-art).

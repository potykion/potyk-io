# Контент-карточка

Карточка-ссылка **с обложкой**: сверху изображение, снизу текст. Живёт в общей [сетке карточек](card-grid.md).

## Зачем

Показывать записи и товары с картинкой: обложка читается сразу, подпись не мешает пропорциям карточки.

## Внешний вид

По умолчанию пропорции **3:4** (портрет). Можно задать **4:3** (альбом) — например для видео с youtube-превью.

Текст под обложкой по центру. При наведении — лёгкая тень и сдвиг вверх (как у любой карточки в сетке).

Под обложкой:

1. **заголовок** (обязательно);
2. **подзаголовок** (опционально) — второй строкой, серым.

Если подзаголовка нет — остаётся одна строка заголовка. Остальной текст превью в карточке не показывается.

## Где используется

- `/food/tasting/sweets` — заголовок: название сладости; подзаголовок: производитель (если есть); 3:4;
- `/mu/artists/<slug>` (блок «Albums») — название альбома; 3:4;
- `/mu/artists/<slug>` (блок «Videos») — название ролика и дата серым; **4:3**;
- записи ленты и разделы с обложкой (например potyk-art) — 3:4.

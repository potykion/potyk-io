# Лента карточек

Переиспользуемый блок «лента»: сетка карточек-ссылок на markdown-страницы из выбранной папки. Одна и та же лента может стоять на главной раздела, на индексной странице подраздела или несколько раз на одной странице с разными источниками.

Раскладка колонок и адаптивность — общий компонент [card-grid](card-grid.md).

## Зачем

Чтобы не собирать оглавление вручную и одинаково показывать статьи/заметки в разных разделах сайта (например блог potyk-mu, позже альбомы и т.п.), с понятным порядком и догрузкой.

## Сценарии

### Показать ленту

На странице (или в её блоке) видна сетка карточек. Каждая карточка — ссылка на страницу: превью текста и при наличии обложка. Клик открывает саму страницу.

### Источник и сортировка

У каждой ленты задаются:

- **папка** с markdown (например блог, альбомы) — в ленту попадают страницы из этой папки (служебные вроде `index` не показываются);
- **порядок**: по дате (новые сверху / старые сверху), случайно, по имени.

На одной странице можно разместить **несколько лент** с разными папками и/или разным порядком — они независимы друг от друга.

### Дата для сортировки

Для порядка «по дате» берётся дата публикации страницы (как у заметки в frontmatter). Если даты нет — страница уходит в конец ленты (при любом направлении сортировки по дате).

### Догрузка

Если карточек больше, чем помещается в первый экран ленты, при прокрутке к концу блока подгружается следующая порция **той же** ленты (тот же источник и порядок), без повторов уже показанных карточек. Другие ленты на странице от этого не меняются.

### Главная potyk-mu (`/mu/`)

На `/mu/` — лента статей из блога, порядок: по дате, новые сверху. Без `cover` — [текстовая](text-card.md) карточка (4:3); с `cover` — [контент](content-card.md)-карточка тоже **4:3** (не дефолтные 3:4). Клик ведёт на страницу блога.

### Исполнители (`/mu/artists/`)

На индексе — лента страниц исполнителей (порядок по имени). На странице исполнителя под текстом — сначала сетка «Albums» (альбомы артиста: название и год), затем «Videos» (ролики из секции `## Videos` в markdown страницы; карточки с обложкой YouTube, названием и датой). Заголовки блоков — по центру, капсом.

### Главная potyk.io (`/`)

На `/` над лентой — секция **«Чем заняться»**: быстрые занятия без ухода в разделы. Кнопки занятий — сетка в **3 колонки** (на узком экране — одна колонка).

- **«Глянуть кинца»** — открывает [модалку](modal.md) с кино-рулеткой (пресет «Посмотреть позже»), колесо сразу крутится само и показывает случайный фильм ([контент-карточка](content-card.md) → Кинопоиск); можно крутить ещё. Если очередь пуста — крутить нельзя.
- **«Свайпать страницы»** — открывает модалку со случайной заметкой публичного potyk-io (целый md-файл). Можно поставить лайк или дизлайк — голос сохраняется, сразу показывается следующая заметка (без повторов уже показанных в этой сессии, пока есть новые). В админке на странице «Разбор заметок» видны все голоса. Голосование и выдача следующей заметки — только для залогиненного.

Ниже — заголовок **«Лента»** по центру и лента публичных заметок сайта в случайном порядке; вперемешку могут попадаться ссылки из меню. Записи дневника и другой контент [potyk-self](../projects/potyk-self.md) в эту ленту не входят. Поведение догрузки то же.

### Главная potyk-self (`/self/`)

На `/self/` — лента заметок раздела (дневник, кулстори, статьи про отношения), порядок случайный. Раздел только для залогиненного.

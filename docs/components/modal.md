# Модалка

Переиспользуемое окно поверх страницы: затемнённый фон и панель с содержимым. Нужна для занятий и других коротких сценариев, которые не уводят со страницы.

## Сценарии

### Открыть

**Что делает пользователь:** нажимает кнопку или ссылку, которая открывает модалку.

**Ожидаемый результат:** поверх страницы появляется панель с содержимым; фон затемнён; фокус на панели; прокрутка страницы под модалкой не мешает.

### Закрыть

**Что делает пользователь:** нажимает крестик, кликает по затемнённому фону или жмёт Escape.

**Ожидаемый результат:** модалка закрывается, страница снова обычная.

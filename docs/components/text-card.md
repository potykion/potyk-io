# Текстовая карточка

Карточка-ссылка **без обложки**: только текст по центру. Живёт в общей [сетке карточек](card-grid.md).

## Зачем

Показывать пункты списков и записи ленты, у которых нет картинки, в том же ритме сетки, что и остальные карточки.

## Внешний вид

Пропорции **4:3**. Заголовок по центру. При наведении — лёгкая тень и сдвиг вверх (как у любой карточки в сетке).

## Где используется

- главная potyk.io (`/`) — текстовые записи ленты и пункты меню без обложки;
- главная potyk-mu (`/mu/`) — лента блога текстовыми карточками (обложки в этой ленте не подставляются);
- potyk-travel (`/travel/`, `/travel/memories/`, `/travel/plans/`) — списки поездок и планов;
- другие места ленты, где у записи нет обложки.

# Разбор YouTube-ссылки

По ссылке на ролик YouTube получить краткие данные о видео — сейчас используется в [Находках](../projects/findings.md) при добавлении.

## Зачем

Не вводить название ролика руками: достаточно вставить ссылку.

## Сценарии

### Получить название ролика

**Что делает пользователь:** вставляет ссылку на YouTube (`youtube.com`, `youtu.be`, мобильный или music.youtube) и отправляет форму, где нужен разбор.

**Ожидаемый результат:**

1. Перед сохранением страница запрашивает у YouTube краткие данные о ролике и берёт **только название** (title). Обложка, автор и прочее не используются.
2. Если название получить удалось — дальше в фиче используется это название.
3. Если название получить не удалось — вместо него подставляется сама ссылка.
4. Пока идёт запрос, кнопка отправки на короткое время недоступна.

### Ссылка не на YouTube

**Ожидаемый результат:** разбор не запускается; дальше в фиче используется сама ссылка (или то, что фича задаёт без YouTube).

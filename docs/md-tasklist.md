# Чекбоксы в markdown

На страницах, собранных из markdown, пункты списка в формате GFM `- [ ]` / `- [x]` отображаются как чекбоксы, а не как обычный текст.

## Зачем

Чтобы списки целей и задач в заметках читались на сайте так же, как в Obsidian.

## Сценарии

### Отмеченный пункт

В markdown: `- [x] покататься на велике` (или `[X]`). На странице — пункт списка с отмеченным, неактивным чекбоксом.

### Неотмеченный пункт

В markdown: `- [ ] поплавать в море`. На странице — пункт с пустым чекбоксом.

### Обычный список

Пункты без `[ ]` / `[x]` после маркера — обычный маркированный список, как раньше.

### Вложенные списки

Чекбоксы работают и во вложенных списках (любые маркеры `-`, `*`, `+`).

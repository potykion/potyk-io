# potyk-invest — сделки (`/invest/deals`)

Учёт депозита, уровней по тикерам и сделок: завести поддержку/сопротивление заранее и быстро оформить покупку с подставленными уровнями.

## Уровни по тикерам

**Зачем:** не вводить поддержку и сопротивление заново при каждой сделке по одному и тому же тикеру.

**Что делает пользователь:** в блоке «Уровни по тикерам» выбирает тикер, указывает поддержку и/или сопротивление, сохраняет.

**Ожидаемый результат:**

1. Уровни сохраняются для тикера (одна запись на тикер; повторное сохранение обновляет значения).
2. Нужен хотя бы один из двух уровней; иначе форма не проходит.
3. Ниже формы — таблица всех сохранённых уровней.

## Добавить покупку

**Что делает пользователь:** в «Добавить покупку» выбирает тикер и заполняет сделку.

**Ожидаемый результат:**

1. Если для тикера есть сохранённые уровни, поля «Уровень входа» (поддержка) и «Уровень выхода» (сопротивление) подставляются автоматически.
2. Подставленные значения можно изменить перед отправкой сделки.
3. Остальное поведение формы сделки без изменений (депозит, объём, TP/SL и т.д.).

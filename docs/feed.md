# Лента карточек

Переиспользуемый блок «лента»: сетка карточек-ссылок на markdown-страницы из выбранной папки. Одна и та же лента может стоять на главной раздела, на индексной странице подраздела или несколько раз на одной странице с разными источниками.

## Зачем

Чтобы не собирать оглавление вручную и одинаково показывать статьи/заметки в разных разделах сайта (например блог potyk-mu, позже альбомы и т.п.), с понятным порядком и догрузкой.

## Сценарии

### Показать ленту

На странице (или в её блоке) видна сетка карточек. Каждая карточка — ссылка на страницу: превью текста и при наличии обложка. Клик открывает саму страницу.

### Источник и сортировка

У каждой ленты задаются:

- **папка** с markdown (например блог, альбомы) — в ленту попадают страницы из этой папки (служебные вроде `index` не показываются);
- **порядок**: по дате (новые сверху / старые сверху), случайно, по имени.

На одной странице можно разместить **несколько лент** с разными папками и/или разным порядком — они независимы друг от друга.

### Дата для сортировки

Для порядка «по дате» берётся дата публикации страницы (как у заметки в frontmatter). Если даты нет — страница уходит в конец ленты (при любом направлении сортировки по дате).

### Догрузка

Если карточек больше, чем помещается в первый экран ленты, при прокрутке к концу блока подгружается следующая порция **той же** ленты (тот же источник и порядок), без повторов уже показанных карточек. Другие ленты на странице от этого не меняются.

### Главная potyk-mu (`/mu/`)

На `/mu/` — лента статей из блога, порядок: по дате, новые сверху. Карточки ведут на страницы блога внутри potyk-mu.

### Главная potyk.io (`/`)

На `/` — лента заметок сайта в случайном порядке; вперемешку могут попадаться ссылки из меню. Поведение догрузки то же.

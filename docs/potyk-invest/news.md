# potyk-invest — новости и страница тикера (`/invest/`)

Дашборд новостей по акциям и рынку: фильтры, кликабельные тикеры и карточка тикера со связанными данными.

## Дашборд новостей

**Зачем:** быстро сузить ленту (дата, сентимент, тикер, сектор) и не держать все сектора развёрнутыми сразу.

### Фильтры

**Что делает пользователь:** на `/invest/` заполняет форму фильтров и применяет (или сбрасывает).

**Ожидаемый результат:**

1. Показываются новости по **акциям** и **рынку/глобалу** (фонды не входят в эту ленту), с учётом выбранных фильтров.
2. **Дата:** можно задать период «с / по»; есть быстрые пресеты (например «последние 7 дней»), которые подставляют даты.
3. **Сентимент:** можно оставить только выбранный тон (например только зелёный); без выбора — все тона.
4. **Тикер:** выбор из справочника тикеров с поиском (как в формах сделок/новостей).
5. **Сектор:** выбор из известных секторов с поиском.
6. Фильтры сочетаются (AND): новость попадает в выдачу, только если проходит все заданные условия.
7. Пустая выдача — понятное пустое состояние, без чужих секторов/тикеров.

### Группировка по секторам

**Ожидаемый результат:**

1. Новости по-прежнему сгруппированы по сектору → тикеру → карточки.
2. Каждый сектор свёрнут в `<details>` (по умолчанию свёрнут или развёрнут — как удобнее при первом открытии; главное — можно свернуть/развернуть).
3. Внутри сектора — те же блоки тикеров и горизонтальные карточки новостей.

### Кликабельные тикеры

**Что делает пользователь:** на дашборде (и в карточке/детали новости, где виден код тикера) нажимает на тикер.

**Ожидаемый результат:**

1. Открывается страница этого тикера.
2. Тикер выглядит как ссылка, а не как обычный текст.

## Страница тикера

**Зачем:** один экран по бумаге — контекст, уровни, сделки и новости без прыжков по разделам.

**Что делает пользователь:** переходит по ссылке на тикер (с новостей или иначе).

**Ожидаемый результат:**

1. Видны **сектор** и **зависимости** тикера (если заданы).
2. Видны **уровни** (поддержка / сопротивление), если заведены.
3. Видны **сделки** по этому тикеру.
4. Видны **новости** по этому тикеру (новые сверху).
5. Если тикера нет в справочнике или данных нет — страница всё равно открывается; пустые блоки не ломают остальное (показывают пусто / «нет данных»).

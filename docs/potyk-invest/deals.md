# potyk-invest — сделки (`/invest/deals`)

Учёт депозита, уровней по тикерам и сделок: завести поддержку/сопротивление заранее и быстро оформить покупку с подставленными уровнями.

## Уровни по тикерам

**Зачем:** не вводить поддержку и сопротивление заново при каждой сделке по одному и тому же тикеру.

**Что делает пользователь:** в блоке «Уровни по тикерам» выбирает тикер, указывает поддержку и/или сопротивление, сохраняет.

**Ожидаемый результат:**

1. Уровни сохраняются для тикера (одна запись на тикер; повторное сохранение обновляет значения).
2. Нужен хотя бы один из двух уровней; иначе форма не проходит.
3. Ниже формы — таблица всех сохранённых уровней.

## Добавить покупку

**Что делает пользователь:** в «Добавить покупку» выбирает тикер и заполняет сделку.

**Ожидаемый результат:**

1. Если для тикера есть сохранённые уровни, поля «Уровень входа» (поддержка) и «Уровень выхода» (сопротивление) подставляются автоматически.
2. Подставленные значения можно изменить перед отправкой сделки.
3. Тейк-профит и стоп-лосс задаются числом и явным выбором единицы: ₽ (смещение от цены покупки), % (процент от цены) или цена (абсолютное значение). Знак для TP/SL выставляется автоматически.
4. Остальное поведение формы без изменений (депозит, объём, связка объём ↔ количество и т.д.).

## Редактировать сделку

**Зачем:** исправить ошибку при вводе или обновить тезис по открытой (и закрытой) сделке.

**Что делает пользователь:** в таблице нажимает «Изменить», правит поля в форме редактирования, сохраняет или отменяет.

**Ожидаемый результат:**

1. Форма предзаполнена текущими значениями сделки, включая TP/SL в формате «число + единица».
2. После сохранения обновляются все поля входа; для закрытой сделки пересчитывается P/L, если изменились цена покупки или количество.
3. «Отмена» возвращает на список сделок без изменений.

## Удалить сделку

**Зачем:** убрать ошибочно заведённую запись.

**Что делает пользователь:** в таблице нажимает «×», подтверждает удаление.

**Ожидаемый результат:**

1. После подтверждения сделка удаляется из базы безвозвратно.
2. Статистика (винрейт, счётчики) пересчитывается при следующем открытии страницы.

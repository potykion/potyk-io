# Инбокс (в админке)

Инбокс идей / багов / задач: набрал на проде (часто с телефона) → выгрузил на локалку в обычные markdown-задачи → разобрал как задачи.

Список и выгрузка живут в админке (подраздел «Инбокс»). Форма «Написать мне» остаётся отдельной публичной страницей.

## Сценарии

### Написать мне

С любой стороны (в т.ч. без логина) можно отправить заметку: выбрать проект и текст. Заметка попадает в инбокс на том сервере, куда ушёл запрос (обычно прод). В меню главной пункт «Написать мне» остаётся.

### Смотреть инбокс

Залогиненный пользователь открывает инбокс из админки:

- **на проде** — список того, что ещё лежит в инбоксе на сервере (карточки с текстом, как раньше);
- **на локалке** — список локальных задач из папки задач.

**На локалке** выполненные задачи в списке **не показываются**. В карточке списка — заголовок, проект и статус, без полного текста.

В списке подразделов админки у «Инбокс» видно число айтемов в текущем списке (красный кружок-бейдж); если пусто — бейджа нет.

Пункта «Инбокс» в меню главной сайта больше нет.

### Открыть задачу (только локалка)

**Зачем:** разобрать заметку отдельно, не листая весь инбокс, и поменять статус, не открывая файл руками.

**Что делает пользователь:** в списке нажимает на задачу.

**Ожидаемый результат:**

1. Открывается отдельная страница этой задачи: полный текст, проект и статус.
2. Можно выбрать другой статус и сохранить.
3. После сохранения на странице виден новый статус.
4. Если задача стала выполненной — она пропадает из списка инбокса; с этой страницы пользователь возвращается к списку.
5. Чужой или несуществующий адрес — нет такой страницы.

На проде отдельных страниц задач нет.

### Выгрузка с прода

Только **на локалке**, из страницы инбокса в админке.

**Зачем:** идеи уже на проде, работать удобнее локально как с markdown-задачами. После успешной выгрузки записи **исчезают с прода**, чтобы серверный инбокс не копился.

**Что делает пользователь:** вводит секрет прода и нажимает «Выгрузить с прода».

**Ожидаемый результат:**

1. Новые заметки с прода появляются локально как файлы задач.
2. Уже выгруженные раньше не дублируются.
3. Выгруженные (и уже локальные) заметки удаляются на проде.
4. Если удаление на проде не удалось, локальные файлы остаются; повторная выгрузка должна дочистить прод.

Секрет — тот, что стоит на проде (не локальный).

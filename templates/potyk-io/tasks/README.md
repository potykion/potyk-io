# Как делать задачи

- заполняем 2 свойства
- `project`
	- potyk-io
	- task-man
	- potyk-fin
- `status`
	- idea/draft - просто идея/черновик, в работу не берем
	- new - можно брать в работу
	- wip - в процессе
	- done - выполнено
- Выполненные задачи делаем status=done  перемещаем в папку tasks/done

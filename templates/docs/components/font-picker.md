# Переключатель шрифта

Плавающий контрол в углу страницы: можно быстро сменить шрифт всего сайта и сравнить варианты. Нужен, чтобы подобрать основной шрифт «на глаз», не пересобирая стили вручную.

**Сейчас выключен** — на страницах не показывается. Включается, когда его снова подключают к общей оболочке сайта.

Базовый шрифт сайта — **Source Sans 3**. Переключатель не заменяет его в вёрстке насовсем: выбранный вариант действует в браузере, пока его не сменят снова.

## Внешний вид

- Компактный блок внизу справа поверх страницы
- Подпись «шрифт» и выпадающий список с названиями семейств
- Сам контрол всегда системным шрифтом, чтобы его было читать при любом выборе

## Сценарии

### Выбрать шрифт

**Что делает пользователь:** открывает список и выбирает другой шрифт.

**Ожидаемый результат:** текст страницы сразу переключается на выбранное семейство; шрифт подгружается при необходимости. Выбор запоминается в браузере и применяется при следующих открытиях страниц сайта.

### Вернуться к базовому

**Что делает пользователь:** снова выбирает Source Sans 3 (или очищает сохранённый выбор в браузере).

**Ожидаемый результат:** страница снова в базовом шрифте сайта.

## Где используется

- общие страницы сайта с общей оболочкой (не отдельная страница входа, если она без этой оболочки).

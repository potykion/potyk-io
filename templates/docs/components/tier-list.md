# Тирлист

- Таблица рейтингов **S → A → B → C → D**: в каждой строке слева буква тира, справа — плитки элементов (картинка или короткое название). 
- Клик по плитке ведёт к связанной записи (якорь на странице или отдельная страница).
- Тирлист показываем если есть хотя бы 1 элемент - пустой тирлист не показываем

## Где используется

- бабл-ти (`/food/thoughts/bubble-tea`) — тирлисты напитков по брендам;
- рестораны (`/food/restaurants`) — при фильтре по тегу, если у попавших рестов задан тир.

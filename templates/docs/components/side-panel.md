# Боковая панель

Переиспользуемая панель, которая выезжает с края экрана поверх страницы. Нужна для меню, инвентаря и других боковых экранов, которые не уводят со страницы.

## Внешний вид

- Панель выезжает **с анимацией** слева или справа
- Поверх страницы — затемнённый фон
- Ширина задаётся сценарием (меню — своя, инвентарь — своя)

## Сценарии

### Открыть

**Что делает пользователь:** нажимает кнопку или другой контрол, который открывает панель.

**Ожидаемый результат:** панель выезжает с выбранного края с анимацией; фон затемнён; прокрутка страницы под панелью не мешает. Если уже была открыта другая боковая панель — она закрывается.

### Закрыть

**Что делает пользователь:** кликает по затемнённому фону, жмёт Escape или снова нажимает кнопку открытия (если это переключатель).

**Ожидаемый результат:** панель уезжает обратно с анимацией, страница снова обычная.

## Где используется

- боковое меню сайта (слева; на узком экране — как эта панель);
- инвентарь на `/game` (справа).

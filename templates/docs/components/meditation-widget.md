# Виджет «Медитировал?»

Карточка с вопросом **Медитировал?** и круглой кнопкой ✓. Отмечает одну медитацию и ведёт на страницу статистики.

## Зачем

Быстро поставить галочку после сессии, не открывая длинные формы. Счётчик живёт в разделе Здоровье; виджет — короткий вход с главной и с `/health/`.

## Где показывается

Только **залогиненному** пользователю:

- главная potyk.io (`/`) — в сетке рядом с виджетом финансов;
- главная potyk-health (`/health/`) — по центру под заголовком раздела.

Без логина виджета нет.

## Внешний вид

Две строки, обе по центру карточки (и по горизонтали, и по вертикали):

1. текст **Медитировал?**;
2. круглая кнопка ✓.

## Сценарии

### Отметить медитацию

Пользователь нажимает ✓ на виджете (на главной или на `/health/`).

**Ожидаемый результат:** счётчик медитаций увеличивается на 1. Страница не перезагружается; на странице статистики числа обновляются, если она открыта.

### Открыть статистику

Пользователь нажимает на текст **Медитировал?**.

**Ожидаемый результат:** открывается `/health/meditation` — заголовок «Медитации», большая кнопка ✓ и стата в две строки: **День / Неделя / Месяц**, затем **Год / Всего**.

### Меню раздела

В меню potyk-health есть пункт **Медитации** → `/health/meditation`.

# Модалка

Переиспользуемое окно поверх страницы: затемнённый фон и панель с содержимым. Нужна для занятий и других коротких сценариев, которые не уводят со страницы.

## Внешний вид

- Затемнённый фон и панель по центру
- Крестик закрытия; клик по фону и Escape тоже закрывают
- На узком экране (≤600px) панель на **всю ширину** экрана, без скруглений по бокам (как «Поесть» на `/game`)

## Поля ввода на мобиле

На iOS фокус в `input` / `textarea` / `select` с `font-size` меньше **16px** зумит страницу; после сабмита зум часто не сбрасывается.

**Ожидаемый результат:** при открытии модалки и фокусе в полях страница не зумится. В полях внутри модалки — `font-size: 16px` (или больше). Не перебивать это через `font: inherit` и прочие стили страницы.

Базово это уже в `modal.css` для `.modal input|textarea|select`. Страничные стили формы не должны опускать размер ниже 16px.

## Сценарии

### Открыть

**Что делает пользователь:** нажимает кнопку или ссылку, которая открывает модалку.

**Ожидаемый результат:** поверх страницы появляется панель с содержимым; фон затемнён; фокус на панели; прокрутка страницы под модалкой не мешает; на мобиле панель на всю ширину; фокус в полях не зумит страницу.

### Закрыть

**Что делает пользователь:** нажимает крестик, кликает по затемнённому фону или жмёт Escape.

**Ожидаемый результат:** модалка закрывается, страница снова обычная (без залипшего зума).

## Где используется

- «Поесть» и книга в инвентаре на `/game`
- создание поста антисоц (`#anti-post`)

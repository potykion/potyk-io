# potyk-mu

## Скачать музыку (`/mu/download`)

### yt-dlp :: Плейлист

- Инпут для ссылки на плейлист типа https://www.youtube.com/playlist?list=PLdSAw7dY_mu7bH6kHlg6O6vYePqdcBC32
- При вставке выводим спинер, получая инфу о плейлисте: 
    - Исполнитель: = автор плейлиста 
    - Альбом: = название плейлиста
    - Год: 
        - Пробуем распарсить год из названия, если он в скобках: `GODFLESH: Songs of Love and Hate (1996)` > `(1996)` > `1996`
            - Если удалось, то из названия убираем: `GODFLESH: Songs of Love and Hate`    
        - Иначе год создания плейлиста
    - Обложка: урл поле с превью; = обложка 1 плейлиста/видео   
    - Треки: 
        - Количество 
        - Вывод порядкового номера 
        - Вывод каждого названия видео из плейлиста в виде инпута
        - Название парсим по возможности, типа если `GODFLESH - Wake`, то парсим по `-` и оставляем только конец: `Wake`
    - Кнопка Скачать
- Кнопка Скачать качает плейлист в виде mp3, теггирует согласно инпутам, возвращает архив, попутно показывая прогресс
- Прогресс 
    - Общий прогресс в % 
    - Вывод текущего этапа, напр. Теггирование
    - Скачивание: вывод скачиваемого трека

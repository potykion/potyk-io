# /game

- базово как / только все убрать
- потом добавить туда в правый левый угол надпись хп, типа `ХП: 1/3`
- рядом с хп выводим кнопку Поесть (только если авторизованы), которая отрывает модалку с 2 полями: прием пищи (завтрак/обед/перекус/ужин), пища (томселект с мультивыбором новых и старых из БД опций) 
  - список пищи в автокомплите не обрезается краями модалки — виден целиком поверх неё
  - на мобиле модалки /game (Поесть и книга из инвентаря) на всю ширину экрана; фокус в полях не зумит страницу (и зум не остаётся после сабмита)
  - при сабмите кладем в скл дату, эти 2 поля
  - увеличиваем хп на 1
  - хп может быть больше чем 3, напр. 4/3 
- по центру выводим большой эмоджи типа 64px эмоджи 🙂/💀(когда хп 0) 
- каждый новый день (с 6 утра мск) хп уменьшается до 0


## Инвентарь

- /game внизу по центру сделать кнопку 🎒
- по нажатии справа открывается [боковая панель](/docs/components/side-panel)
- панель состоит из ячеек, для начала 6x10
- книги в инвентаре — см. [inventory](inventory.md)


## /reads/ & SQL

- /reads/ убираем проп прочитано страниц
- В скл создаём записи о прогрессе страниц + желаем миграцию если у книги был проп
- В скл храним кол-во прочитанных страниц и слаг книги (если потребуются какие-то данные о книге типа обложки, то берём из мд по слагу)

## Инвентарь 

- В инвентарь помещаем все книги, у которых количество прочитанных страниц меньше количества страниц, Выводя их обложку на всю высоту ячейки (в рамках ячейки)
- По клику выводим модалку с инфой о книге: название, автор, обложка, прогресс %
- [Auth] рядом с % — ✏️; по нажатию мини-форма `прочитано / всего` страниц, кнопки Сохранить и Отмена (Отмена просто скрывает форму); сохранение меняет счётчик прочитанных страниц
- на мобиле модалка книги на всю ширину экрана; фокус в поле страниц не зумит страницу (как у модалки «Поесть»)

# Гуляш / рагу

## Рагу с говядиной и овощами

Классическое домашнее рагу: долгое тушение мяса до мягкости и овощи по очереди.

### Ингредиенты:

| Продукты | |
| -------- | ------ |
| Говядина (мякоть) | 700–800 г |
| Картофель | 5–6 шт. |
| Морковь | 2 шт. |
| Лук репчатый | 1–2 шт. |
| Болгарский перец | 1–2 шт. |
| Помидоры (или томаты в собственном соку) | 2–3 шт. (≈200–300 г) |
| Чеснок | 3–4 зубчика |
| Растительное масло | 3–4 ст. л. |
| Томатная паста | 1–2 ст. л. |
| Вода или бульон | ≈200–300 мл |
| Соль, чёрный перец, лавровый лист, паприка | по вкусу |
| Свежая зелень (петрушка или кинза) | для подачи |

### Приготовление:

- Нарежьте говядину средними кубиками (~3–4 см). Разогрейте масло в глубокой сковороде с толстым дном, сотейнике или казане. Обжарьте мясо на сильном огне до золотистой корочки.
- Убавьте огонь, добавьте мелко нарезанный лук и измельчённый чеснок, обжаривайте ещё 5 минут. Добавьте томатную пасту, влейте горячую воду или бульон так, чтобы жидкость слегка покрывала мясо. Накройте крышкой и тушите на минимальном огне 40–60 минут, пока говядина не станет мягкой.
- Нарежьте морковь кружочками или крупными кубиками, картофель и болгарский перец — крупно. Добавьте морковь и картофель к мясу, при необходимости подлейте воды; тушите под крышкой 15–20 минут.
- Добавьте нарезанные помидоры (по желанию без кожицы) и болгарский перец. Посолите, поперчите, добавьте паприку и лавровый лист. Тушите ещё 10–15 минут, пока картофель не станет мягким, а соус не загустеет.
- Выключите огонь, вмешайте рубленую зелень, дайте настояться под крышкой ~10 минут и подавайте.

## Гуляш из говядины с картофелем

### Ингредиенты:

| Продукты | |
| -------- | ------ |
| Говядина | 600 г |
| Картофель | 500 г |
| Перец болгарский сладкий | 250 г |
| Морковь | 100 г |
| Помидоры | 150 г |
| Лук репчатый | 100 г |
| Чеснок | 3–4 зубчика |
| Перец чили свежий | по вкусу |
| Масло растительное (или смалец) | 30–50 мл |
| Паприка молотая | 1–2 ч. ложки |
| Перец красный острый молотый | по вкусу |
| Перец чёрный молотый | 0,5 ч. ложки |
| Соль | по вкусу |

### Приготовление:

- Подготовьте продукты. Вместо растительного масла можно взять смалец.
- Лук нарежьте мелкими кубиками. Разогрейте сковороду с маслом и выложите лук.
- Пассеруйте лук на среднем огне 3–4 минуты, до прозрачности. Всыпьте паприку и молотый красный острый перец, перемешайте.
- Мясо вымойте, обсушите, нарежьте крупными кусочками и выложите к луку.
- Обжарьте на большом огне 2–3 минуты.
- Снизьте огонь до умеренного и тушите мясо с луком под крышкой около 1 часа (выделится сок).
- Помидоры нарежьте кубиками (лучше очистить от кожицы). Чеснок — пластинами, чили без семян — полосками. Морковь — кружками, сладкий перец — квадратиками.
- Когда мясо станет мягким, добавьте морковь, сладкий перец, помидоры, чеснок и чили. Посолите и поперчите.
- Тушите под крышкой 10–15 минут; при выкипании жидкости подлейте воду.
- Картофель нарежьте крупными кубиками, добавьте к мясу и овощам.
- Готовьте под крышкой ещё около 20 минут, до мягкости картофеля.
- Подавайте, украсив зеленью.

## Рагу с говядиной и корнем сельдерея

### Ингредиенты:

| Продукты | |
| -------- | ------ |
| Говядина (лучше ошеек) | 500 г |
| Лук репчатый | 90 г (1 шт.) |
| Морковь | 110 г (1 шт.) |
| Корень сельдерея | 80 г (≈¼ небольшого корня) |
| Розмарин свежий | 1–2 веточки |
| Чеснок | 1 зубчик |
| Масло растительное | 3 ст. ложки |
| Масло сливочное | 30 г |
| Лавровый лист | 1 шт. |
| Перец чёрный горошком | 5–6 шт. |
| Кориандр горошком | 0,5 ч. ложки |
| Соль, молотый чёрный перец | по вкусу |

### Приготовление:

- Нарежьте мясо крупными кусками (~4–5 см). Лук, морковь и корень сельдерея очистите и нарежьте крупно (сельдерей — брусочками или кубиками).
- В кастрюле с толстым дном разогрейте растительное масло. На сильном огне обжарьте говядину до румяной корочки со всех сторон. Посолите, поперчите, переложите на тарелку.
- Убавьте огонь до среднего. Добавьте сливочное масло и выложите лук, морковь и сельдерей. Обжаривайте 5–7 минут до мягкости.
- Верните мясо к овощам. Добавьте чеснок (целый или раздавленный), розмарин, лавровый лист, перец горошком и кориандр. Влейте горячую воду или бульон почти до покрытия.
- Доведите до кипения, убавьте огонь до минимума, накройте крышкой и томите 1,5–2 часа, пока мясо не станет мягким.
- По желанию часть воды замените красным сухим вином; к гарниру — пюре, рис или полента.

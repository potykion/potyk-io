# Макароны с мясом в томатном соусе

- https://www.russianfood.com/recipes/recipe.php?rid=164739

![Макароны с мясом в томатном соусе](https://www.russianfood.com/dycontent/images_upl/555/big_554324.jpg)

## Ингредиенты:

| Продукты | |
| -------- | ------ |
| Свинина (корейка без кости) | 300 г |
| Макароны | 250 г |
| Томатный сок | 200 мл |
| Морковь | 50 г |
| Перец сладкий | 40 г |
| Лук репчатый | 40 г |
| Масло растительное | 40 мл |
| Петрушка | 2 веточки |
| Соль | по вкусу |
| Перец чёрный молотый | по вкусу |
| Вода | 200 мл |

## Приготовление:

- Свинину промойте, обсушите, нарежьте средними кусочками. Подойдёт любая часть свинины, не слишком жирная.
- В сковороде разогрейте масло на среднем огне, выложите кусочки свинины и обжаривайте 3–4 минуты. Затем убавьте огонь, томите мясо под крышкой 15 минут.
- Пока мясо готовится, очистите лук и сладкий перец. Нарежьте морковь брусочками, лук — полукольцами, перец — полосками.
- Выложите лук к мясу и обжаривайте вместе 2–3 минуты, помешивая.
- Морковь отправьте к мясу, перемешайте.
- Добавьте сладкий перец и перемешайте. Обжаривайте мясо с овощами 4–5 минут. Посолите и поперчите.
- Влейте томатный сок и тушите мясо с овощами 25 минут.
- Петрушку промойте, мелко нарежьте. Добавьте зелень в сковороду.
- Вскипятите 200 мл воды. В сковороду выложите макароны, влейте горячую воду.
- Перемешайте макароны с овощами, тушите всё вместе на медленном огне под крышкой 10 минут, до мягкости макарон.
- Подавайте в горячем виде.

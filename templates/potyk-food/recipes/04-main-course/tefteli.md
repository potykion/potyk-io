# Тефтели с рисом с подливкой

![Тефтели с рисом с подливкой](https://img.iamcook.ru/old/upl/recipes/zen/u5846-b80988809a7a35ff14942418623a6875.jpg)

## Ингредиенты:

| Продукты | |
| -------- | ------ |
| Фарш мясной (свинина + говядина) | 500 г |
| Рис круглозёрный | 80 г |
| Лук репчатый | 1 шт. |
| Яйцо куриное | 1 шт. |
| Мука (для панировки) | 2–3 ст. л. |
| Соль | по вкусу |
| Перец чёрный молотый | по вкусу |
| Масло растительное | для обжарки |

Для подливки:

| Продукты | |
| -------- | ------ |
| Сметана 15–20% | 2 ст. л. |
| Томатная паста | 1 ст. л. |
| Мука | 1 ст. л. |
| Вода или бульон | 300 мл |
| Лавровый лист | 1–2 шт. |

## Приготовление:

- Рис промыть и отварить до полуготовности (примерно 5–7 минут после закипания), откинуть на дуршлаг и остудить.
- Лук мелко нарезать или натереть на тёрке. В миске соединить фарш, остывший рис, лук и яйцо. Посолить, поперчить и тщательно вымесить руками.
- Смачивая руки в холодной воде, сформировать небольшие круглые шарики (с крупный грецкий орех или мандарин). Каждую тефтелю слегка обвалять в муке.
- Разогреть сковороду с растительным маслом и быстро обжарить тефтели на среднем огне со всех сторон (примерно по 3 минуты) до лёгкой золотистой корочки.
- В отдельной ёмкости смешать сметану, томатную пасту и 1 ст. л. муки, залить тёплой водой или бульоном. Размешать венчиком или вилкой до однородности, без комочков.
- Залить соусом тефтели в сковороде, добавить лавровый лист, убавить огонь до минимума и накрыть крышкой. Тушить 20–25 минут, пока подливка загустеет.

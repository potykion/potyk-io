# Пастуший пирог (Shepherd's Pie)

- https://youtu.be/72EuzIZIB5k

## Ингредиенты:

На форму глубиной 6 см, площадью примерно с лист A4 (325×230×60 мм).

| Продукты | |
| -------- | ------ |
| Фарш бараний (можно говяжий) | 1,5 кг |
| Картофель | 1,5 кг |
| Морковь | 250 г |
| Сельдерей | 150 г |
| Лук репчатый | 400 г |
| Горошек (замороженный или свежий) | 250 г |
| Перец свежемолотый | 1 ч. л. (без горки) |
| Паприка | 1 ч. л. (с горкой) |
| Чеснок | 4 зубчика (по желанию) |
| Соль | 1 ч. л. (с небольшой горкой) |
| Тимьян (только листья) | 1 ст. л. (с небольшой горкой) |
| Вустерский соус | 50 мл |
| Вино белое столовое | 200 мл |
| Мука | 2 ст. л. |
| Томатная паста | 1 ст. л. (с горкой) |
| Концентрат бульона или куриные кубики | 1 ст. л. / 2 кубика |

### Для картофеля:

| Продукты | |
| -------- | ------ |
| Пармезан мелко тёртый | 100 г |
| Творожный сыр | 100 г |
| Молоко | 50–100 мл |
| Сливочное масло | 50 г |

## Приготовление:

- Морковь, сельдерей и лук мелко нарежьте.
- Картофель отварите до готовности.
- Фарш обжарьте вместе с луком. Добавьте муки, перемешайте и приправьте.
- Добавьте томатной пасты, овощей, перемешайте и залейте вином. Выпарите и добавьте вустерский.
- Залейте бульоном и дождитесь, пока фарш загустеет (целый ком фарша должен медленно сползать с ложки).
- Из готового картофеля сделайте пюре. К пюре добавьте тёртый пармезан и творожный сыр.
- В отдельную форму выложите на дно фарш и сверху пюре.
- Уберите в духовку с режимом верхнего обдува при 200 °C на 10 минут.

# Печень говяжья по-строгановски

- https://www.russianfood.com/recipes/recipe.php?rid=156121

![Печень говяжья по-строгановски](https://www.russianfood.com/dycontent/images_upl/414/big_413717.jpg)

## Ингредиенты:

| Продукты (на 4 порции)         |              |
| ------------------------------ | ------------ |
| Печень говяжья                 | 500 г        |
| Сметана 20-25%                 | 250 г        |
| Лук репчатый                   | 100 г        |
| Мука                           | 2 ст. ложки  |
| Соль                           | по вкусу     |
| Перец чёрный молотый           | по вкусу     |
| Вода                           | 100 мл       |
| Масло растительное для жарки   | 2-3 ст. ложки |

## Приготовление:

- Подготовить продукты. В процессе готовки понадобится небольшой полиэтиленовый пакет.
- Говяжью печень промыть, срезать плёнки и прожилки. Нарезать полосками.
- Отправить нарезанную печень в пакет.
- Добавить к печени муку.
- Завязать пакет и встряхнуть, чтобы мука распределилась по кусочкам печени.
- Лук очистить, промыть и нарезать полукольцами.
- В разогретой сковороде с растительным маслом обжарить лук 3-5 минут, до прозрачности или лёгкой румяности.
- Выложить в сковороду с луком печень и обжарить на сильном огне, помешивая, 2-3 минуты.
- Добавить сметану, соль и молотый перец. Влить воду, перемешать. Накрыть крышкой и тушить на малом огне 15-20 минут.

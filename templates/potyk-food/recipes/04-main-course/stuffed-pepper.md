# Фаршированный болгарский перец

- https://www.russianfood.com/recipes/recipe.php?rid=135955

![Фаршированный болгарский перец](https://www.russianfood.com/dycontent/images_upl/143/big_142756.jpg)

## Ингредиенты:

| Продукты                         |                |
| -------------------------------- | -------------- |
| Перец болгарский некрупный       | 17–19 шт.      |
| Фарш свино-говяжий               | 1 кг           |
| Рис                              | 1 стакан       |
| Морковь                          | 1–2 шт.        |
| Лук репчатый                     | 2 шт.          |
| Зелень петрушки                  | по вкусу       |
| Соль                             | 2 ч. ложки     |
| Специи (чёрный перец и др.)      | 2 ч. ложки     |
| Масло растительное               | для жарки      |

Для заливки:

| Продукты       |           |
| -------------- | --------- |
| Томатная паста | 1 ст. л.  |
| Сметана        | 2 ст. л.  |
| Вода           | 2 стакана |
| Соль           | 1 ч. ложка |
| Специи         | 1 ч. ложка |

Для подачи:

| Продукты |          |
| -------- | -------- |
| Сметана  | по вкусу |

## Приготовление:

- Перец помыть, срезать верхушку и удалить семена. Морковь и лук почистить: лук нарезать мелкими кубиками, морковь натереть на тёрке.
- Рис промыть и отварить 5–7 минут до полуготовности. Откинуть на сито, остудить и добавить к фаршу.
- Лук и морковь обжарить на растительном масле до мягкости и добавить к фаршу.
- Посолить начинку (1 ч. ложка), добавить специи (1 ч. ложка) и мелко нарезанную петрушку. Тщательно перемешать.
- Плотно нафаршировать перец и уложить вертикально в широкую кастрюлю.
- В стакане смешать томат-пасту со сметаной, влить воду (около 1 стакана), добавить соль (1 ч. ложка) и специи (1 ч. ложка), перемешать.
- Залить перец подготовленной смесью, затем долить ещё около 1 стакана воды (не выше края перца).
- Довести до кипения и готовить на небольшом огне под крышкой около 30–40 минут. Снять с огня и дать постоять ещё 10 минут.
- Подавать со сметаной и соусом, в котором варился перец.

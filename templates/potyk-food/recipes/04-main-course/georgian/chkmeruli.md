# Чкмерули (курица по-грузински)

- https://www.russianfood.com/recipes/recipe.php?rid=147631

![Чкмерули (курица по-грузински)](https://www.russianfood.com/dycontent/images_upl/279/big_278280.jpg)

## Ингредиенты:

| Продукты              |        |
| --------------------- | ------ |
| Курица                | 800 г  |
| Масло сливочное       | 50 г   |
| Сливки 20%            | 200 мл |
| Кинза                 | 1 пучок |
| Чеснок                | 4–5 зубчиков |
| Хмели-сунели          | по вкусу |
| Соль                  | по вкусу |
| Перец чёрный молотый  | по вкусу |

## Приготовление:

- Небольшую курицу или цыплёнка вымыть, обсушить бумажными полотенцами. Разрезать тушку по грудке вдоль, распластать на доске, накрыть плёнкой и отбить молотком. Посолить и поперчить.
- В сотейнике разогреть сливочное масло, выложить курицу спинкой вниз. Накрыть плоской тарелкой и сверху поставить груз (например, кастрюлю с водой). Жарить под гнетом 15 минут с одной стороны на среднем огне.
- Перевернуть курицу спинкой вверх, снова установить гнет и жарить ещё 10 минут на среднем огне.
- Уменьшить огонь и довести курицу до готовности в течение примерно 20–25 минут, переворачивая попеременно обеими сторонами и каждый раз устанавливая гнет. Курица готова, когда сок при проколе прозрачный, а не розовый.
- Для соуса мелко нарезать кинзу, очистить и порубить чеснок.
- Растолочь кинзу с чесноком, солью, перцем, добавить немного хмели-сунели.
- Влить сливки и немного воды, размешать.
- Залить обжаренную курицу сливочным соусом, накрыть крышкой и потушить на медленном огне 10 минут. В процессе перевернуть, чтобы курица хорошо пропиталась соусом.
- Подавать горячим вместе с соусом; к столу — тонкий лаваш и свежие овощи.

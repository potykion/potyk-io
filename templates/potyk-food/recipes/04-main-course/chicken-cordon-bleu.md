## Ингредиенты:

| Продукты |        |
| -------- | ------ |
| Куриное филе | 3–4 шт. (по 150–200 г) |
| Ветчина | 3–4 ломтика |
| Сыр твёрдый | 3–4 ломтика |
| Масло сливочное | 3–4 тонких слайса |
| Яйца | 2 шт. |
| Мука | 100 г |
| Сухари панировочные | 100 г |
| Паприка молотая | 1–2 ч. л. |
| Базилик сушёный | 1 ч. л. |
| Соль | по вкусу |
| Перец чёрный молотый | по вкусу |

## Приготовление:

- Куриное филе разрезать на тонкие слайсы (или отбить целую грудку), накрыть плёнкой и отбить до толщины около 0,6 см.
- Посолить, поперчить.
- На каждый кусок выложить ломтик ветчины и сыра, свернуть рулетиком; края при необходимости скрепить зубочистками.
- Смешать панировочные сухари с паприкой и базиликом.
- Обвалять рулетики в муке, окунуть во взбитые яйца, затем обвалять в сухарях.
- Выложить в форму, сверху на каждый рулетик положить слайс сливочного масла.
- Запекать в духовке при 190 °C 10–15 минут, до готовности курицы (сок должен быть прозрачным).
- Перед подачей вынуть зубочистки.

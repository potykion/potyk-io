# Битые огурцы

Хрустящая закуска на 200 г огурцов: 10 минут на соль плюс пара минут на сборку. Огурцы отбивают, чтобы трещины впитали заправку, а соль вытягивает лишнюю воду — соус не разбавляется.

## Ингредиенты

| Продукты | Количество |
| --- | --- |
| **Основа** | |
| Свежие огурцы | 200 г (1 длинный или 2 средних) |
| Соль (для вытягивания влаги) | 1/4 ч. л. |
| Чеснок | 1–2 зубчика |
| Свежий перец чили | 1/3 стручка (по вкусу) |
| Кинза | 2–3 веточки (или немного зелёного лука) |
| Жареный кунжут | 1 ч. л. |
| **Заправка** | |
| Чёрный уксус Longmen | 1 ст. л. |
| Соевый соус Ichida Shoyu | 2 ч. л. |

| Сахар | 1/2 ч. л. |

## Приготовление

- **Отбейте и посолите.** Отрежьте у огурцов кончики и придавите их плоской стороной широкого ножа или скалкой, чтобы они треснули вдоль. Нарежьте крупными кусочками наискосок по 2 см. Посыпьте щепоткой соли, перемешайте и оставьте в дуршлаге на 10 минут, затем слейте выделившуюся воду.
- **Смешайте заправку.** В пиале соедините чёрный уксус, соевый соус, кунжутное масло и сахар, размешайте до растворения кристаллов.
- **Соберите перед подачей.** Мелко порубите чеснок ножом, нарежьте чили тонкими колечками, порубите кинзу. За 2–3 минуты до подачи смешайте отжатые огурцы со специями и заправкой, посыпьте кунжутом и сразу несите на стол.

## Нюансы

- **Зачем отбивать.** Трещины увеличивают площадь соприкосновения с заправкой — именно поэтому битые огурцы вкуснее ровно нарезанных.
- **Не заправляйте заранее.** Через 10–15 минут огурцы дадут сок и станут водянистыми, поэтому соус добавляют перед самой подачей.
- **Вариации.** Для сытности добавьте горсть жареного арахиса, для свежести — ещё немного кинзы. Чили регулируйте по вкусу, семена оставляйте по желанию.

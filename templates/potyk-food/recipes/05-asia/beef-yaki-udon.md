# Яки удон с говядиной

- https://www.youtube.com/shorts/VJVh7GlMc64

![Яки удон с говядиной](https://i.ytimg.com/vi/VJVh7GlMc64/hqdefault.jpg)

## Ингредиенты:

| Продукты |  |
| -------- | ------ |
| Говяжий стейк (рибай, рамп или другой нежный) | 250 г |
| Лапша удон | 400 г |
| Пак-чой (или бок-чой / чой-сум) | 2 головки |
| Грибы | 100 г |
| Чеснок, мелко нарезанный | 1 ст. л. |
| Лук репчатый, тонкими слайсами | 1 шт. |
| Зелёный лук, тонкими слайсами | 2 стебля |
| Растительное масло | 2 ст. л. |
| **Соус** |  |
| Мирин (или шаосин) | 2 ст. л. |
| Светлый соевый соус (или обычный) | 2 ст. л. |
| Тёмный соевый соус | 1 ст. л. |
| Сахар | 1 ст. л. |
| Кунжутное масло | 1 ч. л. |
| Кукурузный крахмал | ½ ч. л. |

## Приготовление:

- Смешать ингредиенты соуса до однородности.
- Говядину нарезать тонкими полосками против волокон. Пак-чой разделить на листья (толстые стебли нарезать крупнее). Грибы нарезать.
- Удон подготовить по инструкции на упаковке (обычно обдать кипятком или коротко прогреть), откинуть.
- На сильном огне разогреть масло, обжарить говядину до румяности, переложить.
- В той же сковороде обжарить лук и чеснок, добавить грибы и пак-чой, быстро прожарить.
- Вернуть мясо, добавить удон и соус, всё перемешать и прогреть, пока соус слегка загустеет и покроет лапшу.
- Посыпать зелёным луком и сразу подавать.

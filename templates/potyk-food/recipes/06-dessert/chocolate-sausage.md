# Кондитерская колбаска

## Ингредиенты:

| Продукты |  |
| -------- | ------ |
| Сахар | 1 ст. |
| Вода | 3 ст. л. |
| Сливочное масло | 100 г |
| Какао | 1,5 ст. л. |
| Яйцо | 1 шт. |
| Печенье | 250 г (~14 шт. стандартных) |
| Орехи | по вкусу |
| Изюм | по вкусу |

## Приготовление:

- Сахар, воду, сливочное масло, какао и яйцо перемешать, поставить на огонь и довести до закипания.
- Печенье раскрошить, смешать с орехами и изюмом.
- Соединить печенье с орехами и изюмом с горячей шоколадной смесью, хорошо перемешать.
- Завернуть массу в форме колбаски (в плёнку или пергамент).
- Убрать на холод до застывания.

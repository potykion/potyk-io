# Пряная тыквенная запеканка с манкой

- https://www.youtube.com/watch?v=Fq4OKU_oHtg

![Пряная тыквенная запеканка с манкой](https://i.ytimg.com/vi/Fq4OKU_oHtg/hqdefault.jpg)

## Ингредиенты:

| Продукты |  |
| -------- | ------ |
| Тыква | 600 г |
| Творог 9% | 700 г |
| Манка | 100 г |
| Яйца | 3 шт. |
| Сахар | 100 г |
| Ванильный сахар | 10 г |
| Лимон (цедра) | 1 шт. |
| Кардамон молотый | 1 ч. л. |
| Корица молотая | ½ ч. л. |
| Куркума | 1 ч. л. с горкой |
| Сливочное масло | 10 г |
| Соль | щепотка |
| **Для подачи** |  |
| Сметана 20% | 60 г |
| Сгущёнка | 70 г |
| Корица молотая | 1 ч. л. |

## Приготовление:

- Тыкву нарезать на дольки, очистить от кожицы и удалить семечки. Отварить дольки в кастрюле с водой под крышкой около 20 минут. Откинуть на сито и перебить погружным блендером в пюре. Добавить кардамон и корицу.
- В творог добавить яйца, ванильный сахар, сахар и щепотку соли. Перебить погружным блендером до однородной нежной консистенции. Натереть цедру лимона к творожной массе и перемешать лопаткой.
- Переложить в творожную массу тыквенное пюре, добавить куркуму и перемешать. Добавить манку (80 г) и перемешать.
- Форму для выпекания 20×25 см смазать сливочным маслом (борта и дно) и посыпать манкой (20 г).
- Перелить творожно-тыквенную массу в форму.
- Запекать в заранее разогретой до 180 °C духовке 45 минут. Готовой запеканке дать остыть и зафиксироваться.
- Нарезать на порции и подавать со сметаной и сгущёнкой, посыпать щепоткой корицы.

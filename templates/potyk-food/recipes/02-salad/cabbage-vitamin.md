# Салат из капусты «Витаминный»

- https://www.russianfood.com/recipes/recipe.php?rid=133759

![Салат из капусты «Витаминный»](https://www.russianfood.com/dycontent/images_upl/117/big_116679.jpg)

## Ингредиенты:

| Продукты              |          |
| --------------------- | -------- |
| Капуста               | 5 кг     |
| Перец болгарский      | 1 кг     |
| Лук репчатый          | 1 кг     |
| Морковь               | 1 кг     |
| Соль                  | 4 ст. л. |
| Сахар                 | 340 г    |
| Масло растительное    | 0,5 л    |
| Уксус 9%              | 0,5 л    |

## Приготовление:

- Подготовить продукты.
- Нарезать лук полукольцами.
- Перец нарезать соломкой.
- Морковь натереть.
- Нашинковать капусту.
- Смешать масло, уксус, соль и сахар. Этим маринадом залить капусту.
- Очень аккуратно перемешать.
- Разложить в банки, утрамбовать плотно.
- Хранить в холодном месте.

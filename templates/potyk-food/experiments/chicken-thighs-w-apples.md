# Куриные бёдрышки, запечённые с яблоками в медово-горчичном соусе

- https://www.russianfood.com/recipes/recipe.php?rid=167925

![Куриные бёдрышки, запечённые с яблоками в медово-горчичном соусе](https://www.russianfood.com/dycontent/images_upl/612/big_611326.jpg)

## Ингредиенты:

| Продукты (на 3 порции)           |                              |
| -------------------------------- | ---------------------------- |
| Куриные бёдрышки                 | 850 г (3 шт.)                |
| Яблоки                           | 200 г (1 крупное или 2 средних) |
| Мёд                              | 25 г                         |
| Горчица (готовая приправа)       | 25 г                         |
| Масло растительное без запаха    | 20 мл                        |
| Сок лимонный                     | 5 мл                         |
| Паприка молотая                  | 1 ч. ложка                   |
| Соль                             | по вкусу                     |
| Перец чёрный молотый             | по вкусу                     |
| Кунжут (для подачи)              | 5 г                          |

## Приготовление:

- Подготовьте все ингредиенты. Яблоки возьмите с плотной мякотью и кисло-сладким вкусом.
- Куриные бёдра хорошо вымойте и обсушите бумажным полотенцем. При необходимости обрежьте лишний жир. Натрите курицу со всех сторон солью и молотой паприкой. Полейте лимонным соком (1/2 ч. ложки).
- В глубокую миску влейте растительное масло без запаха, добавьте горчицу, оставшийся лимонный сок и мёд. Поперчите по вкусу.
- Все ингредиенты хорошо перемешайте. Медово-горчичный соус готов.
- Включите духовку для разогрева до 180 градусов. Яблоко вымойте и обсушите салфеткой. Разрежьте пополам и удалите семена. Половинки яблок нарежьте дольками. Куриные бедрышки переместите в форму для запекания. Выложите яблочные дольки в пустоты между кусочками куриного мяса.
- Смажьте курицу и яблоки несколько раз медово-горчичным соусом. Оставшийся соус вылейте в форму для запекания. Отправьте курицу с яблоками в разогретую духовку, запекайте 40-50 минут, до румяной корочки.
- Куриные бёдрышки готовы. Посыпьте кунжутом и подавайте к столу.

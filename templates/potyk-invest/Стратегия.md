# Стратегия (core + spec)

Заменяет по смыслу старые [[Принципы]] — там был только режим свинга на весь портфель. Здесь два режима + кэш.

## Доли

| Корзина | Доля | Зачем |
|---|---|---|
| **Core** | ~60% | Хорошие бизнесы: рост + дивы, держать долго |
| **Spec** | ~30% | Свинг 2нед–2мес по идее / уровню / событию |
| **Кэш** | ~10% | TMON / кэш между идеями |

Допустимый старт: 50/40/10. Не раздувать акции до 100% без идеи.

## Общее (на всё)

- Только акции + денежный фонд (TMON). Без опционов, фьючерсов, плеча
- **≤ 5%** портфеля на 1 бумагу (и core, и spec)
- После продажи spec → новая идея **или** TMON, не «лишь бы купить»
- Разбор / сделки: спокойно (сб), не интрадей
- У каждой позиции ярлык: `core` | `spec` | `exit` и одна строка «зачем»

## Core (~60%)

- 8–12 имён, не 20 похожих из одного сектора
- Вход: качество, отчёт, топы (свои / Вася), адекватная цена
- Выход: **тезис сломан**, сильно переоценено, или ротация в лучший core
- Стопа −10% **нет**. Просадка ≠ сигнал продать, если тезис жив
- Дивы → в core или в TMON
- Пересмотр: раз в месяц / после отчёта

Примеры ядра: банки и фин (SBER, T, DOMRF, MOEX), отборный ритейл/ИТ с тезисом (X5, HEAD), сильные див-истории (SNGSP). Не складывать полпортфеля в «сети».

## Spec (~30%)

- 4–8 слотов (при 5% это как раз ~20–40%)
- Вход: уровень, катализатор, идея в `Сделки/` (статус wip)
- Таргеты: **−10% стоп**, **+20%** цель (можно частично +10 / +20)
- Срок: **2 недели – 2 месяца**. Нет результата и нет новой причины → выход в TMON
- Не усреднять ниже стопа «потому что понравилась»

Примеры: OZON после прилёта, PLZL от уровня, RAGR после дивов.

## Кэш (~10%)

- TMON / рубли
- Парковка после фиксации spec и буфер под август / шоки
- Не обязан сразу реинвестировать дивы и профит

## Чеклист перед покупкой

1. Это **core** или **spec**?
2. Есть слот ≤ 5%? Не раздуваю один сектор?
3. Spec: где −10 и +20? Какой катализатор? Карточка в `Сделки/`?
4. Core: какой тезис на месяцы? Почему не заменить уже имеющимся core?
5. Откуда деньги — TMON / продажа exit / новая ликвидность?

## Чего не делать

- Вешать правила spec (−10 / +20) на core
- Держать spec «как дивидендную» без срока
- 5–6 бумаг одного сектора под видом диверсификации
- Докупать к стопнутому spec без нового тезиса

# `shards`

Рандомные мысли, подобные осколкам стекла. Когда-то они составляли целую картину, зеркало, а теперь они лишь режут мою менталку, и собрать их во что-то целое не получается. Чтобы собрать что-то целое нужно неизбежно перечитывать это, раз за разом переигрывать опыт, а это мне не интересно, скучно, такая природа.

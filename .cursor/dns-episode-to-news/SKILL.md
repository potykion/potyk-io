# ДнС → новости по тикерам

## Когда применять

Пользователь даёт путь к конспекту в `Источники/Деньги не спят/` (или уже написанный выпуск) и просит создать новости / тикеры.

## Вход

1. Файл источника, напр. `Источники/Деньги не спят/YYYY-MM-DD ДнС <название>.md`
2. Шаблон: `_TEMPLATES/Новость.md`
3. Образцы: `Новости/* ДнС *.md`, `Тикеры/*.md`

## Workflow

Скопируй чеклист и отмечай:

```
- [ ] 1. Разобрать конспект на блоки (тикер / макро)
- [ ] 2. Сопоставить с тикерами vault
- [ ] 3. Создать недостающие тикеры (+ русское имя)
- [ ] 4. Дописать русское имя существующим без него; обновить ссылки
- [ ] 5. Создать файлы новостей
- [ ] 6. Проверить YAML и ссылки
```

### 1. Разбор конспекта

Каждый блок обычно: имя → `тек`/цена → тезисы → `сентимент` 🟢/🟡/🔴.

Макро-блоки (не акции):

| В конспекте | Тикер (файл) | Имя новости |
|---|---|---|
| imoex | `IMOEX TMOS` | `ДнС IMOEX` |
| ртс | `RTSI` | `ДнС RTS` |
| глобал | `Глобал` | `ДнС Тезисы` |
| rgbi | `RGBI ОФЗ` | `ДнС RGBI ОФЗ` |
| кс | `КС` | `ДнС КС` |
| валюта | `CNY USD` | `ДнС CNY` |
| нефть | `BRENT` | `ДнС BRENT` |

### 2. Имена файлов тикеров

Формат: `Тикеры/<TICKER> <Русское>.md` (если русское уже в имени — не дублировать).

Примеры: `ALRS Алроса.md`, `SVCB Совком.md`, `MAGN ММК.md`, `T Т-Банк.md`.

Новый тикер — минимальный frontmatter по аналогии с похожими:

```yaml
---
Сектор:
  - <сектор>
---
```

Секторы как в соседних файлах: Фин, ИТ, Нефтянка, Металл, Магаз, Товары, Комм, Газ, Драг, Материалы, Недвига, Телеком, Хп, Алюм, Транспорт, Мир, Индекс.

### 3. Обновление ссылок после переименования

Во всех `.md` vault заменить на полное имя **без алиаса** (иначе Bases группирует по `|alias`):

- `[[TICKER]]` → `[[TICKER Русское]]`
- `[[Тикеры/TICKER]]` → `[[TICKER Русское]]`
- `[[Тикеры/TICKER|TICKER]]` / `[[Тикеры/TICKER Русское|TICKER]]` → `[[TICKER Русское]]`

Не оставлять `|OZON` и т.п. — только `[[OZON Озон]]`. Длинные коды раньше коротких (`SNGSP` до `T`).

### 4. Новости

Путь: `Новости/YYYY-MM-DD ДнС <код>.md`  
Дата = дата в имени источника. Для макро с русским в имени файла — как раньше (`RGBI ОФЗ`, `КС`, `Тезисы`).

Frontmatter строго по `_TEMPLATES/Новость.md`:

```yaml
---
datetime: YYYY-MM-DDTHH:mm:ss
ticker: "[[TICKER Русское]]"
source: "[[YYYY-MM-DD ДнС <название выпуска>]]"
summary: Краткий конспект блока
price: "123"
sentiment: 🟢
---
```

Правила:

- `source` = wiki-ссылка на файл источника (имя без `.md`)
- `ticker` = полное имя заметки тикера (с русским), в кавычках
- `summary` — сжатый смысл блока (1–3 фразы). **Не дублировать текущую цену** (`тек`) — она только в `price`. Уровни/таргеты/диапазоны в summary оставлять. Если есть `:` — брать summary в кавычки
- `price` — из `тек`; нет цены → `price:` пустой
- `sentiment` — как в конспекте
- `datetime` — дата выпуска; время можно `20:00:00`, если неизвестно
- тело файла обычно пустое (без хвоста «Новость»), кроме редких развёрнутых блоков как у IMOEX

### 5. Проверка

- На каждый блок конспекта есть файл в `Новости/`
- Нет тикеров без русского имени среди затронутых акций
- Wiki-ссылки на переименованные тикеры обновлены
- YAML валиден (кавычки при `:` в summary)

## Не делать

- Не коммитить без просьбы
- Не переименовывать тикеры вне выпуска, если пользователь не просил «все»
- Не путать MGNT/MAGN, SNGSP/SNGS, TATNP/TATN

# Ответы м1

Язык — русский. Пользователь пишет от своего имени; агент только черновит реплики.

## Кто есть кто

- **м1** — Мила (Mila), бывшая.
- **м2** — текущая партнёрша. **Можно упоминать**: м1 про неё знает. Без хвастовства, сравнения с м1 и интимных деталей. Если поездка/быт связаны с м2 — говорить прямо («у родственников девушки»), не маскировать под «своих родных».
- **л1** — человек, с которым м1 видели вместе (дневник 2026-08-06). В ответы не тащить, пока пользователь сам не сказал.

## Когда

Пользователь кидает сырые сообщения (часто с датой и именем `Mila`) или просит «ответь / сгенерируй ответ».

## Контекст

Перед ответом быстро сверить факты:

1. Свежие `templates/potyk-io/diary/YYYY-MM-DD.md` (и поездки рядом по дате).
2. Что пользователь поправил в этом чате — это сильнее дневника.

Не выдумывать поездки, людей и эмоции. Если факта нет — формулировка общая или спросить одной строкой.

### Факты, которые уже всплывали

- Загар ~август 2026: был **у родственников м2** (пгт Бытошь, Брянская обл.): велик, солнце, оффлайн. Для м1 ок: «у родственников девушки / у родственников в пгт, на велике катал».

## Тон

По умолчанию: лёгкий, короткий, вежливый, без флирта и без «давай встретимся». Не оправдываться, не допрашивать в ответ, не раскрывать карусель/секс/тревогу.

Если пользователь задал режим (`теплее` / `суше` / `с юмором`) — следовать ему до отмены.

Цель по умолчанию: вежливый контакт, не вовлечение и не отталкивание.

## Вывод

1. Один **рекомендуемый** черновик — готовый к копипасту (как в мессенджере: короткие строки, можно 1–2 эмодзи).
2. По желанию ещё 1–2 варианта (короче / чуть подробнее).
3. Не разжёвывать психологию, если не спросили. Одна строка «почему так» — ок, если есть ловушка (приглашение, ревность, допрос).

## Правки пользователя

Уточнение факта («не у родных, у родственников м2») сразу правит следующие черновики. Новые правила тона/цели — дописать сюда в скилл, если пользователь явно просит зафиксировать.

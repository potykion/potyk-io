# Diary review (неделя / месяц)

Пишет обзоры по записям в `templates/diary`. Язык — русский. Тон — прямой, близкий к дневнику: без корпоративного HR-спича, можно честно и колко, но структурированно.

## When

- «обзор недели» / «что думаешь» / «сравни с предыдущей»
- «обзор месяца»
- явный запрос по `templates/diary` на ретроспективу

## Paths & naming

| Тип | Файл | Заголовок |
|-----|------|-----------|
| Неделя | `templates/diary/YYYY-Www.md` (ISO week) | `# Обзор недели · ДД мон – ДД мон YYYY (Www)` |
| Месяц | `templates/diary/YYYY-MM.md` | `# Обзор месяца · месяц YYYY` |

Ссылки на дни: `/diary/YYYY-MM-DD` (без `.md`). Ссылка на недельный обзор: `/diary/YYYY-Www`.

Не путать с ежедневными `YYYY-MM-DD.md` и с `Шаблоны/`.

## Workflow

1. **Период**
   - Неделя: пн–вс относительно «сегодня» из user_info (или даты, которую назвал пользователь).
   - Месяц: календарный месяц; если записей мало — явно написать, что срез неполный.
2. **Собрать файлы** `templates/diary/YYYY-MM-DD.md` за период + за **предыдущий** такой же период (для сравнения).
3. **Прочитать все** дневники периода (и предыдущего). Учитывать YAML/фронтматтер (`Муд`, `Медитировал?`, `Секс`, `Интерес`, `Энергия` и англ. варианты вроде `mood`).
4. **Не тащить** в обзор посторонние заметки папки (`Invest faq`, `Трени`, длинные эссе), кроме случая когда дневник на них ссылается или дата совпадает с поездкой (например `suzdal-cucumber-26` ↔ 2026-08-01).
5. **Написать** файл обзора по шаблону ниже. Если файл уже есть — обновить, не плодить дубликаты.
6. **Обновить** `templates/diary/index.md`: H1 сохранить; список ссылок — дни (новые сверху или хронологично desc) + обзоры недели/месяца. Не включать `Шаблоны/` и служебное, если в индексе их не было принято держать.
7. В ответе пользователю — короткий вердикт (5–10 предложений) + пути к созданным файлам. Полный текст — в файлах, не дублировать обзор целиком в чат.

## Шаблон недели

```markdown
# Обзор недели · ДД мон – ДД мон YYYY (Www)

Дни: [ссылки через ·]

## Картина недели
2–4 предложения: дуга настроения и главный сюжет.

## Что было важным
Буллеты по темам (тело, деньги, близость, работа/ИИ, проекты, поездки…).

## Тело / еда / секс
Коротко, если есть в записях; не выдумывать.

## Что думаю
Оценка агента: что сильно / что буксует / какой сдвиг. От первого лица агента («что думаю»), без морализаторства.

## Сравнение с прошлой неделей (…–…)
Таблица или короткие контрасты: темп, инвест, тело, голова, проекты, выходные.
В конце — 1–2 предложения «коротко: …».

## На следующую неделю
3–5 конкретных пунктов из текста записей, не абстрактные «больше воды».
```

## Шаблон месяца

```markdown
# Обзор месяца · месяц YYYY

Оговорка, если срез неполный.

## Образ месяца
Один абзац-метафора/суть.

## Сквозные темы
Нумерованный список 4–7 тем с опорой на записи.

## Муд и энергия
Динамика по фронтматтеру и тексту.

## Что получилось / Что буксует
Два списка.

## Итог одним абзацем

## На следующий месяц
3–5 пунктов.
```

## Rules

- Только факты из записей + явная интерпретация в блоке «Что думаю» / итогах. Не выдумывать события.
- Сохранять лексику автора, где уместно (без цензуры смысла), но обзор — связный текст, не копия дневника.
- ISO-неделя: пн = начало; номер недели — ISO (`W31` и т.д.).
- После обзора недели всегда есть сравнение с предыдущей, если для прошлой недели есть хотя бы 1–2 записи; иначе написать, что сравнивать не с чем.
- Ответ пользователю — на русском.

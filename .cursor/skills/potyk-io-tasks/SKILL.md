# Задачи potyk-io

Язык ответа — русский. Перед работой прочитай `templates/potyk-io/tasks/README.md` и этот скилл.

## README (кратко)

Свойства в YAML frontmatter:

- `project`: `potyk-io` / `task-man` / `potyk-fin`
- `status`:
  - `idea` / `draft` — не брать
  - `new` — можно в работу
  - `wip` — уже в процессе
  - `done` — выполнено

Выполненные задачи **перемещаем** в `templates/potyk-io/tasks/done/`.

## Workflow

1. Прочитай `templates/potyk-io/tasks/README.md`.
2. Собери `templates/potyk-io/tasks/*.md` (не `done/`, не `.obsidian`) с `status: new`.
3. Каждую задачу — **отдельно**, до конца, потом следующую.
4. Для каждой:
   1. Прочитай файл целиком.
   2. Сделай задачу в коде/контенте.
   3. Поставь `status: done`, **перенеси** файл в `templates/potyk-io/tasks/done/` (не копируй).
   4. **Сразу коммить** только файлы этой задачи (см. ниже).
5. В ответе: список задач (было → стало) + что сделано + хеш коммита по каждой.

## Коммит после задачи

**Обязательно** после каждой задачи — отдельный коммит. Не копи изменения нескольких задач в один коммит.

Формат:

```text
тип(scope): суть задачи

Refs: templates/potyk-io/tasks/done/Fix-menu-mobile.md
```

- Тип: `feat` / `fix` / `refactor` / `docs` / `chore` / …
- **Scope обязателен** — `menu`, `hashtags`, `notes`, `feed`, `tasks`, …
- **Refs** — путь к файлу задачи в `done/` (после переноса)

### Что включать в коммит

Только файлы, изменённые **в рамках этой задачи**: код, стили, контент, перенос файла задачи в `done/`. Чужие незакоммиченные правки и посторонние файлы (`tasks/.obsidian/`, чужие `feat-*.md`) — **не трогать**.

### Общие файлы между задачами

Если один файл менялся в нескольких задачах (`render.py`, `md-content.css`), коммить **поэтапно**: в коммите задачи N — только её часть diff (при необходимости временно откати лишнее, закоммить, верни остальное для следующей задачи).

### Порядок

```
задача → done → git add (только свои файлы) → git commit → следующая задача
```

## Что не трогать

- `status: idea` / `draft` / `wip` / `done`
- чужие незакоммиченные файлы
- `tasks/.obsidian/`

# Новая сделка / идея

## Когда применять

Пользователь просит завести идею или сделку: тикер, цена входа, тезис, срок.

## Вход

1. Тикер + тезис (уровень, катализатор, горизонт)
2. Шаблон: `templates/potyk-invest/_TEMPLATES/Сделка.md`
3. Образцы идей: `Сделки/PLZL по 1000.md`, `Сделки/IRAO после падения.md`
4. Образцы wip: `Сделки/OZON после прилета.md`, `Сделки/2026-08-10 - RAGR -.md`
5. Тикер-файл в `Тикеры/` для wiki-ссылки
6. Стратегия: `Стратегия.md` (≤5%, spec −10/+20, срок 2нед–2мес; длиннее — явно в карточке)

## Именование файла

| status | Имя файла | Пример |
|---|---|---|
| `idea` | `{TICKER} {краткий тезис}.md` | `SELG по 42.md`, `PLZL по 1000.md`, `IRAO после падения.md` |
| `wip` / `close` | `YYYY-MM-DD - {TICKER} - {дата выхода или пусто}.md` | `2026-08-10 - RAGR -.md` |

Без дублей: если идея уже есть — обновить, не плодить.

## Frontmatter (обязательные ключи)

Копировать ключи из шаблона. Заполнять так:

| Поле | idea | wip |
|---|---|---|
| `ticker` | `"[[TICKER Русское имя]]"` как в `Тикеры/` | то же |
| `status` | `idea` | `wip` |
| `Причина входа` | тезис / wiki на новость | то же |
| `datetime open` | пусто | факт входа `YYYY-MM-DDTHH:mm:00` |
| `Объем депа %` | `"5"` (если не сказали иначе) | факт |
| `Цена покупки` | уровень входа строкой/числом | факт |
| `Лотов` / `Итого покупка` | пусто | факт |
| `Таргет` | если дали; иначе пусто (не выдумывать) | −10/+20 или явный |
| `Срок` | дата/горизонт если дали | если есть |
| `datetime close` … `PROFIT/LOSS` | пусто | для close — заполнить |
| `Ошибки` / `Мысли` | опционально; ссылка на новость ДнС | уроки / заметки |

Wiki на тикер: имя файла из `Тикеры/` без `.md` (напр. `[[SELG Селигдар]]`). Если тикера нет — создать по паттерну dns-skill / существующих файлов.

## Workflow

```
- [ ] 1. Прочитать шаблон + 1–2 похожие сделки
- [ ] 2. Найти тикер в Тикеры/; при отсутствии — создать
- [ ] 3. Создать/обновить файл в Сделки/
- [ ] 4. Добавить пункт в Идеи.md (чеклист под свежим источником, если есть)
- [ ] 5. Сверить с Стратегией (доля, горизонт, core vs spec)
```

### Идеи.md

- Чекбокс `- [ ]` + wiki на карточку или короткий текст
- Группировать под выпуском/источником (`## [[YYYY-MM-DD ДнС …]]`), если идея оттуда
- Не трогать чужие топы без нужды

## Не делать

- Не ставить `wip` без реального входа (дата/лоты/сумма)
- Не выдумывать таргет, лоты, P/L
- Не коммитить без просьбы
- Не рекомендовать плечо / деривативы

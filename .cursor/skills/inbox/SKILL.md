# Inbox

Язык ответа — русский.

## Спека

Источник правды по **поведению**: `docs/inbox.md`.

Там только функционал (сценарии и ожидаемый результат). **Не тащи в спеку** реализацию: маршруты, SQL, имена функций, заголовки, env, пути модулей — это код.

Перед изменением поведения инбокса:

1. Прочитай `docs/inbox.md`.
2. Меняй код так, чтобы совпадало со спекой.
3. Если меняется поведение для пользователя — обнови `docs/inbox.md` в том же изменении (снова только функционал).

## Где код (не в спеке)

`potyk_io_back/inbox/`, `templates/inbox/`. Локальные задачи после выгрузки — `templates/potyk-io/tasks/`, дальше как `potyk-io-tasks`.

# Синхронизация заметок с телефона

Язык ответа — русский. Источник: телефонный vault → репозиторий на компе.

## Пути

| Роль | Путь |
|------|------|
| Телефон / OneDrive (источник) | `c:\Users\admin\OneDrive\Рабочий стол\Fvck` |
| Дневники на источнике | `Fvck\Diary\YYYY-MM-DD.md` |
| Шаблоны на источнике | `Fvck\Шаблоны\` |
| Прочие заметки на источнике | `Fvck\*.md` (корень vault) |
| Назначение | `templates/potyk-io/diary/` |

Не копировать: `_obsidian/`, картинки без запроса, папку драфтов (`Драфты …`), если пользователь явно не попросил.

## Правила

### Дневник (`YYYY-MM-DD.md`)

**По дневнику синхроним только новые заметки — старые не трогаем.**

- Новый = файла `templates/potyk-io/diary/YYYY-MM-DD.md` ещё нет.
- Если файл уже есть в репо — **не перезаписывать**, даже если на телефоне длиннее/свежее.
- Не мержить содержимое и не «дотягивать» правки в существующие дни без явного запроса («перезапиши 2026-08-30» и т.п.).

### Остальные заметки

Остальные заметки можно синхронить как надо:

- корневые `Fvck\*.md` (не дневники) → `templates/potyk-io/diary/` с тем же именем;
- отсутствующие — добавить;
- уже есть, но содержимое разошлось — обновить с телефона (телефон источник правды для не-дневников);
- шаблоны из `Fvck\Шаблоны\` → `templates/potyk-io/diary/Шаблоны/`.

**Не удалять `created`:** если в репо у заметки уже был YAML-ключ `created`, при перезаписи с телефона его сохранить (вмержить во frontmatter). Не затирать `created` слепым copy с телефона.

## Workflow

1. Сверить `Fvck\Diary\` с `templates/potyk-io/diary\`:
   - список имён `YYYY-MM-DD.md` только на источнике → **скопировать**;
   - пересечение → **пропустить** (старые не трогаем).
2. Пройти корневые `Fvck\*.md` (кроме случайных не-md): скопировать/обновить в diary.
3. При необходимости обновить шаблоны из `Fvck\Шаблоны\`.
4. Обновить `templates/potyk-io/diary/index.md`: в блок «Дни» добавить ссылки на **новые** даты (новые сверху), не ломая блок «Обзоры».
5. В ответе коротко: сколько дневников добавлено (имена), какие прочие заметки добавлены/обновлены, что пропущено из дневников как уже существующее (если уместно одной строкой).

## Копирование на Windows

Для путей с кириллицей надёжнее пофайлово через .NET, не `Copy-Item -Filter`:

```powershell
[System.IO.File]::Copy($srcPath, $dstPath, $overwrite)
```

Для дневников `$overwrite = $false` и копировать только если `Test-Path $dstPath` — false. Для прочих заметок можно `$overwrite = $true`.

## Не делать

- Не затирать существующие `YYYY-MM-DD.md` «чтобы выровнять с телефоном».
- Не синхронизировать в обратную сторону (репо → Fvck), пока не попросили.
- Не коммитить без явной просьбы.
